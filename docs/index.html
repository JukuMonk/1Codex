1Codex / Терминал / инженерный атлас

От задачи
до проверенного
результата в 1С

Агент находит нужные объекты, меняет конфигурацию и проверяет её на данных и в интерфейсе. Результаты проверок сохраняются в отчёте.

ДействиеРазвилкаПроверкаРезультатНастройка проектаОшибка / возврат

На каждой схеме узел открывает пояснение, выходной файл и ссылку на исходник. Tab и Enter работают с клавиатуры. Кнопка «Развернуть» открывает большую схему; «100%» увеличивает подписи.

Этап 7 из 12

Проверить данные и серверную логику через COM

Внешнее соединение исполняет проектные проверки и сверяет числа. Формы и клиентские события проверяются отдельно.

Пример проверяемого инварианта

Почему двух остатков недостаточно

Учебная иллюстрация, не результат запуска 1С

Операция должна быть отклонена: минимум внутри периода −1.

Серая линия показывает исходную историю, пунктир показывает результат выбранного изменения. Через COM проверяются остатки по событиям. UI-сценарий проверяет отказ и сообщение пользователю. После отказа прежние движения должны сохраниться.

1Codex

Атлас описывает библиотеку 1.1.0. Для каждого проекта описанные тесты нужно запускать отдельно.

Сверено с исходниками 8faed4be0a5609dbc970fdceed19980449602283. В счётчик tools входят все Python-файлы каталога, включая служебные.

Координаты узлов рассчитывает Dagre 3.1.3. Готовый файл содержит SVG, CSS и JavaScript; для просмотра сеть не нужна.
