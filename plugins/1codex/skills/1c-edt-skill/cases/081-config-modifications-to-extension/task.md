# Доработки типовой конфигурации → расширение: генератор по двум выгрузкам

**Проект и платформа.** НПЦАП (`C:\gold\NPCAP`), 1С:ТОИР КОРП 3.0.8.1 (БСП, защита СЛК) с доработками Деснол прямо
в конфигурации (41 новый объект, 43 изменённых типовых, ~12 тыс. строк BSL), платформа 8.3.27.2342, режим
совместимости 8.3.21, файловая база, без EDT. Октябрь 2026.

**Задача.** Вынести ВСЕ доработки в расширение: основная конфигурация — чистая поставка, доработки — только в
расширении. Исходный материал — `.cf` ПРОД.

**Что пошло не так.**
1. Поставку, на которой сделаны доработки, искать не пришлось: она лежит в самом `.cf` —
   `Ext/ParentConfigurations/<Имя>.cf` в выгрузке (`/DumpConfigToFiles`). Загрузить её во вспомогательную базу и
   выгрузить — точная «база» для сравнения.
2. Загрузка расширения из XML: «Текущее ChildObjects, ожидаемое CommonForm» (общая форма — не контейнер);
   «свойство ThisNode типа InternalInfo отсутствует» (план обмена); «Неизвестная команда Report.X.StandardCommand.Open»
   (командный интерфейс подсистемы скопирован из ПРОД целиком).
3. `/UpdateDBCfg -Extension`: «Добавление дочерних объектов этого типа к заимствованным в расширениях недопустимо в
   режиме совместимости 8.3.21 и ниже» — для измерения/ресурсов регистров; то же с реквизитом вместо ресурса;
   на 8.3.22 — то же «8.3.22 и ниже», и «Режим совместимости расширения конфигурации больше режима совместимости
   основной конфигурации». На поставке с совместимостью 8.3.25 — «8.3.25 и ниже».
4. Первое обновление ИБ через COM с подключённым расширением: «Не удалось обновить права ролей конфигурации …
   Найдены подключенные расширения конфигурации, изменяющие роли конфигурации» (`РегистрСведений.ПраваРолей`).
5. `РасширениеКонфигурации.Записать()` через COM: «Предупреждение безопасности … Подключить расширение?».
6. Кнопка в форме (ПРОД менял `Form.xml` одной формы): заимствованная форма из выгрузки реального расширения
   хранит только структуру элементов без путей данных, реквизитов, команд и событий — переносить так `Form.xml` по
   памяти рискованно (кейс 074: такая выгрузка не грузится обратно).
