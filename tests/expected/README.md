# tests/expected — эталоны к tests/tasks.md

`T01.md … T24.md` — решения и признаки правильного ответа; `fixtures/` —
исходные сломанные файлы для задач-диагностик (T06, T07, T12, T16),
пересобираются `python fixtures/make_fixtures.py` (форма) — остальные
написаны руками и лежат как есть.

Как оценивать: критерии в `tasks.md` — необходимый минимум; решение
считается верным, если выполнены все критерии И модель назвала кейсы/правила,
на которые опиралась, И не заявила непроверенного («в базе открывается»
без прогона). Модель имеет право на другое равноценное решение, если
объяснила, чем оно равноценно.
