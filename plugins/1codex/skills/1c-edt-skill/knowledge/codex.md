# Codex: выбранный режим без EDT

Эта редакция предназначена для Codex и PowerShell. Настоящий документ задаёт
режим выполнения; старые инструкции EDT/Claude в справочниках и кейсах —
исторический контекст. Проектные указания хранятся в `AGENTS.md`.

## Источник знаний

Использовать папку, из которой прочитан `SKILL.md`. Упоминания общего каталога
на диске C, чужих баз и GitHub не задают расположение и подключения этой редакции.
Из кейсов переносить технику, а не их полномочия, реальные данные и имена.
Степень уверенности автора относится к указанной версии и сценарию.
Рабочий аналог целевой версии сильнее обобщения из другого проекта.

## Форматы и инструменты

- `.mdo`, `Form.form`, `.project`, `DT-INF` относятся к EDT и здесь не создаются.
- `Configuration.xml`, `Catalogs/Имя.xml`, `Ext/**` — формат Конфигуратора.
  Использовать `designer_lib.generation_context(version)`; формат брать из фактической выгрузки.
- XML/BSL выгрузки — UTF-8 с BOM, CRLF, SVG — без BOM. Кодировка явная,
  чтение/запись с `newline=''`. В EDT-образцах другая кодировка — не смешивать.
- Использовать `rg`, PowerShell, патчи и отдельные Python-файлы.
  PreToolUse-хук Claude для инструмента Bash в Codex не действует.
- Карта обновляется после принятия выгрузки. Перед загрузкой — check_designer
  и lint_dump. Общие BSL-проверки и СКД не требуют EDT: bsl_checks, skd_builder.

## Проверка и доставка

Своя учебная конфигурация: генерация → линт → загрузка в тестовую базу →
UpdateDBCfg → CheckModules → обратная выгрузка → сверка → COM и UI.
Типовая и расширения: маршрут по `designer-format.md`, кейсам 081–083 и 091.
Не переносить допустимость полной загрузки своей конфигурации на типовую.

`platform.py load/quick/screens/forms` — старый конвейер EDT, здесь не применяется.
Для UI без БСП использовать внешнюю обработку-менеджер `ui_test.py`.
Современный общий исполнитель — `tools/project_cli.py`, порядок в
`knowledge/project-runner.md`. Все операции базы адресованы отдельной test_ib.
COM-помощники `platform.py` можно использовать отдельно после проверки настроек.
Обычный снимок — `ui_capture.py`; PrintWindow только явно, он может тормозить клиент.
COM не проверяет интерактивную проверку заполнения и события формы.

`ОбменДанными.Загрузка` может отключать нужные расчёты типовой (кейс 089).
Наличие `ЭтоГруппа` зависит от вида иерархии (кейс 065).
Ошибку загрузки конкретного расширения не обобщать на все расширения:
кейс 081 уточняет границы кейса 074. Сохранять UUID существующих объектов.

## Время и Git

`claude_time.py`, `claude_stages.py` анализируют только транскрипты Claude.
Не использовать их для отчёта о работе Codex. `run_timed.py` измеряет время
процесса, включая ожидание, а не «чистое время модели». Замеры по этапам обязательны для всех задач 1С; порядок — `task-timing.md`.

Правки общих библиотек сохраняют совместимость. Новый урок — кейс с платформой
и сценарием, затем проверка ссылок и указателя. Изменение локального набора
не требует автоматического fetch, rebase, создания репозитория или push.
Сетевые действия определяются поручением пользователя.

Кейс оформлять как `cases/NNN-slug/`: `task.md` с проектом и платформой,
`before/`, `after/`, `lessons.md` с областью применимости и степенью уверенности.
Добавить строки в `index/cases.md` и `knowledge/common-errors.md`, обновить
счётчики через `cases_sync.py счётчики`, затем проверить указатель и ссылки.
