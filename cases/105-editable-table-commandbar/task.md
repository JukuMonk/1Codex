# Редактируемая табличная часть без кнопки добавления

Проект: UP, ДиЗ-14, 29.10.2026. Платформа 8.5.1.1529, совместимость 8.5.1.
Формат: XML Конфигуратора, собственная конфигурация. Confidence: HIGH.

COM записывал строки, форма открывалась, но методолог не мог добавить подвкладку через интерфейс.
В таблице остались значения построителя по умолчанию: запрет изменения строк и выключенное автозаполнение панели.
После исправления проверены загрузка, CheckModules, добавление штатной кнопкой, выбор ссылки,
запись, повторное открытие и две проверки сохранённых данных через COM. Снимок просмотрен.
