# Уроки

**Симптом.** Генерация блока падает: «{(15, 4)}: Поле не найдено "К.Код"»; в другом месте — «Поле не найдено ОбъектыЭксплуатации.ЭтоГруппа»; служебный запрос — «Ожидается …» на `КАК В`.

**Почему.** (1) У `Справочник.Календари` БСП длина кода 0 — поля `Код` нет. (2) `ЭтоГруппа` есть только у справочников с иерархией групп (`HierarchyOfItems` без групп — поля нет). (3) `В` — ключевое слово языка запросов (оператор В), как псевдоним не годится; то же для `ИЛИ`, `И`, `КАК`…

**Что изменилось.** Сортировка по наименованию; условия `ЭтоГруппа` только там, где у справочника есть группы; псевдонимы с латинским префиксом.

**Правило.** Поле стандартного реквизита (Код, Номер, ЭтоГруппа, Владелец, Родитель) использовать только после проверки `.mdo`: `codeLength` > 0, `hierarchyType` = HierarchyFoldersAndItems, `owners`. Псевдонимы не из ключевых слов.
