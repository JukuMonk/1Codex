# Уроки

**Отложенные обработчики — регламентным заданием, не синхронным вызовом.** `ВыполнитьОтложенноеОбновлениеСейчас`
(как и БСП при `ВыполнитьОбновлениеИЗавершитьРаботу`) — один поток; задание `ОтложенноеОбновлениеИБ` — потоки по
`КоличествоПотоковОбновленияИнформационнойБазы` (0 → значение по умолчанию; у УТ 11.5 — 8 в
`ОбновлениеИнформационнойБазыПереопределяемый`). На окно работ расписанию задания снять время начала (каждый день,
каждые 60 с), блокировку регламентных — снять; после — вернуть расписание заказчика. Сначала прочитать расписание:
у заказчика оно может быть «с 19:00». Переход с синхронного на задание безопасен: снять процесс и его сеанс
(`TerminateSession`), задание продолжит с той же порции.

**БСП 3.1 обновляет ИБ фоновыми заданиями** — признак «идёт» = активные фоновые задания с «обновлен» в описании, а не
`НеобходимоОбновлениеИнформационнойБазы()`. Снятый клиент → завершить его сеанс в кластере (агент:
`GetSessions` / `TerminateSession`, только свои сеансы своей базы).

**После реструктуризации — статистика СУБД** (`sp_updatestats` / `VACUUM ANALYZE`) до обработчиков обновления.

**Ход долгого обработчика — по SQL**, а не по `ПрогрессВыполнения` (у многих пусто): `sys.dm_exec_requests`
(растут `logical_reads`), `sys.dm_exec_query_profiles` (rebind по внешнему циклу), число строк очереди
`_…ChngR` с `JOIN` на таблицу узлов плана `ОбновлениеИнформационнойБазы` — два замера с интервалом дают скорость и
прогноз.

**Значения перечисления доработки → элементы справочника поставщика.** До обработчиков, переводящих данные по
`ПеречислениеСтавкаНДС`, создать элементы справочника для своих значений (иначе строки останутся без ставки); после —
очистить у своих элементов связь с перечислением (значения уходят из конфигурации в следующем релизе). Свои элементы
— с ПОСТОЯННЫМИ GUID (`УстановитьСсылкуНового`): у справочника нет поля для метки, наименования совпадут с элементами
поставщика, а слияние позже (`ОбщегоНазначения.ЗаменитьСсылки`) должно их однозначно находить. Значения
перечисления загружать до `/UpdateDBCfg` пакетом из файла перечисления — без `Configuration.xml` (case 091).
