# Уроки кейса 080

1. **`.dt` помнит версию платформы.** Выгрузка базы 8.5.1 (заголовок `1CIBDmpF3`) загружается только платформой
   8.5.1 и новее. Версию выбирать по режиму совместимости конфигурации из установленных в `C:\Program Files\1cv8\`;
   `CREATEINFOBASE File="…"` и `/RestoreIB` — одной и той же версией.
2. **Формат файлов выгрузки — по платформе**: 8.3.27 пишет `version="2.20"`, 8.5.1 — `version="2.21"`. Объекты,
   которые генератор добавляет в чужую выгрузку, должны быть в её формате: `designer_lib.VERSION = '2.21'` до сборки.
   Проверка: `grep -o 'version="2\.[0-9]*"' Configuration.xml`.
3. **Данные без внешнего соединения и без `/Execute`** — обработкой ВНУТРИ конфигурации локальной копии:
   выгрузить конфигурацию копии в файлы, добавить обработку с формой (`ПриСозданииНаСервере` — работа,
   `ПриОткрытии` — `ЗавершитьРаботуСистемы(Ложь)`), `register_in_configuration`, загрузить `-listFile` только новые
   файлы и `Configuration.xml`, `/UpdateDBCfg`, открыть `1cv8c ENTERPRISE … /URL "e1cib/app/Обработка.<Имя>"`.
   Обработка конфигурации не вызывает «Предупреждение безопасности»; права на неё даёт полная роль; рабочая база
   не меняется (`after/make_export_dp.py`). Другой путь — пользователь копии с `ПредупреждатьОбОпасныхДействиях
   = Ложь` (кейс 078).
4. **Универсальная выгрузка в JSON** (`after/ВыгрузкаВJSON.bsl`): обход `Метаданные.Справочники`, `Документы`,
   `РегистрыСведений`, `Константы`; ссылка — `{ref: УникальныйИдентификатор, type: имя объекта}`; перечисление —
   `XMLСтрока`; дата — `XMLСтрока` (местное время сервера без зоны: зону добавляет загрузчик); `ХранилищеЗначения`
   пропускается; реквизиты с «пароль» в имени не выгружаются; табличные части — массивы строк в `_tables`;
   пустые даты — `null`; один файл на объект метаданных, `_журнал.json` — счётчики. Файлы — UTF-8 с BOM
   (`encoding="utf-8-sig"` при чтении).
5. **`/UpdateDBCfg` применяет всё отложенное.** Если в рабочей базе структура не обновлена, копия применит и чужие
   изменения: до загрузки своей обработки выполнить `/UpdateDBCfg` отдельно и прочитать журнал — это находка для
   владельца базы, а не следствие выгрузки.
6. **Чужая база — чужие секреты.** В коде самописных конфигураций встречаются адреса вебхуков с ключами и строки
   COM-подключения с паролями: в отчёт — факт и место, без значений; в выгрузку для переноса — без паролей.
