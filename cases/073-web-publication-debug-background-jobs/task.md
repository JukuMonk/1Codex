# Веб-клиент: отчёты «пустой результат» и ошибка фонового расчёта — отладка в публикации без адреса отладчика

**Объекты.** Файловая база, опубликованная на Apache 2.4 (Windows), веб-клиент: формы отчётов БСП (формирование фоновым заданием через `ДлительныеОперации`), панель показателей на начальной странице (фоновый расчёт данных).

**Проект: ФРЕГАТ EAM (EDT 2026.1, платформа 8.5.1.1529, режим совместимости 8.3.16, БСП 3.1.3), публикация на удалённом сервере.**

**Симптомы.**
- Любой отчёт в веб-клиенте: «Не удалось сформировать отчет (пустой результат)»; в тонком клиенте тот же отчёт формируется.
- На начальной странице: «Процедура или функция с указанным именем не определена (ЗаписатьJSON)» — вторичная ошибка: клиентский код формы выводил текст ошибки фонового задания через `ЗаписатьJSON`, которой в веб-клиенте нет.
- После замены `ЗаписатьJSON` панель показала настоящую причину: «Не удалось рассчитать показатели: Ошибка регистрации предмета отладки в отладчике».

**Причина.** В `default.vrd` публикации — `<debug enable="true" protocol="http" url=""/>`: отладка разрешена, адреса отладчика нет. Сеанс фонового задания при старте регистрируется в отладчике и падает; основной сеанс веб-клиента работает. Локальная публикация той же базы с выключенной отладкой работала.

**Результат.** `<debug enable="false"/>` (или флажок «Отладка → Разрешено» снят в утилите публикации), перезапуск Apache — отчёты формируются, панель считается.

**Confidence:** HIGH (воспроизведено: удалённая публикация с отладкой — ошибка, локальная без — работает; после правки vrd — работает).
