# Уроки

**Симптом.** После `python tz/G5.py` в git-diff проекта — десятки файлов: из модулей пропали `#Иначе ВызватьИсключение …` (обёртка координатора), у форм сбилась раскладка шапок.

**Почему.** Поздние этапы (координатор, раскладка) дорабатывают файлы, которые ранние генераторы пишут целиком. Запуск раннего этапа по отдельности возвращает «сырое» состояние.

**Что изменилось.** Любая правка источника генератора → `build_all.py` целиком; признак правильной сборки — git-diff проекта содержит только намеренные файлы.

**Правило.** В цепочке генераторов отдельный этап запускать только для отладки; в проект — всегда полная цепочка и проверка diff.
