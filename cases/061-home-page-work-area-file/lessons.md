# Уроки

**Симптом.** В `Configuration.mdo` свойства начальной страницы нет (в модели EDT это `transient`-ссылка); искать его там бесполезно.

**Почему.** Состав начальной страницы EDT хранит отдельным файлом `Configuration/HomePageWorkArea.hpwa` (пространство `homePageWorkArea`): шаблон колонок и формы слева/справа.

**Что изменилось.** Файл пишет генератор подсистемы (`НАЧАЛЬНАЯ_СТРАНИЦА`): одна колонка, форма обработки. Настройка пользователя (Вид → Настройка начальной страницы) сильнее умолчания конфигурации.

**Коммиты.** MVM 786c4b9 (подсистема_логистики.py).

**Ссылки.** `knowledge/subsystems-and-ui.md` §6.
