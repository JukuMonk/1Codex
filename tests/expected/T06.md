# T06 — сломанная форма

Четыре дефекта фикстуры `fixtures/broken-form/Form.form` (см. README там):

| Дефект | Кейс | Исправление |
|---|---|---|
| нет `<saveWindowSettings>true</saveWindowSettings>` перед `<autoTitle>` | 002 | вернуть тег на место (после `<autoCommandBar>`/`<extendedTooltip>` формы, как в образце) |
| реквизит `Лимит` `<types>Number</types>` без `<numberQualifiers>` | 001 | добавить `<numberQualifiers><precision>15</precision><scale>2</scale><nonNegative>false</nonNegative></numberQualifiers>` или удалить реквизит |
| колонка `Отметка` с `<id>1</id>` = номер реквизита `Объект` | 003 | вернуть свободный номер из ОБЩЕГО пространства реквизитов и колонок |
| у таблицы `Строки` нет `<searchStringAddition>` | 004 | вернуть блок спутника с подсказкой и контекстным меню и его номерами элементов |

Ожидаемый способ поиска: `python tools/check_project.py` на копии
песочницы с подменённой формой — сообщения ссылаются на кейсы; либо diff с
образцом `examples/metadata/data-processor/…/Form.form`. «Гадание по
внешнему виду» (мобильность, таблица) — неверный ход (case 006).

Верный отчёт: «XML валиден, EDT покажет пустой лист; найдено четыре
причины; после исправления `check_form` молчит; в EDT не открывалось».
