# Уроки

**Симптом.** Обновление базы из EDT: «Ошибка загрузки/выгрузки конфигурации … Forms/Файлы/Ext/Form.xml: Неверный путь к данным: "Список.Description"» — по КАЖДОМУ полю списка, включая `Список.Ref`. EDT validate видел только «Значительная, form-data-path».

**Почему.** Платформа не скомпилировала произвольный запрос динамического списка целиком: (1) `ИЗ Справочник.Файлы`, хотя основная таблица — свой справочник; (2) `ССЫЛКА Справочник.ПапкиФайлов`, а в `ОпределяемыйТип.ВладелецФайлов` конфигурации нет `ПапкиФайлов` — ССЫЛКА на невозможный тип не компилируется. Инкрементальная загрузка неизменённые формы не перепроверяет — дефект «спал» до чистой загрузки.

**Что изменилось.** Источник — свой справочник; ветка `ЛОЖЬ` вместо невозможной ССЫЛКИ; в определяемый тип возвращён нужный тип. Проверка — загрузка в ПУСТУЮ базу: EDT export → `1cv8 CREATEINFOBASE` → `DESIGNER /LoadConfigFromFiles` → `/UpdateDBCfg` (`tools/platform.py load`).

**Правило.** «Неверный путь к данным» по всем полям списка = ошибка в тексте запроса списка. Копируя форму БСП, переписывать ИЗ и условия ССЫЛКА под свой объект. Перед сдачей — загрузка в пустую базу той платформой, что у пользователя.
