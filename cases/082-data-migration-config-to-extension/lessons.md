# Уроки кейса 082

1. **Переход «доработки в конфигурации → поставка + расширение» без переноса данных теряет данные доработок.**
   Порядок (`after/migrate.py`, `after/test_migration.py`):
   1. `выгрузить` в базе со старой конфигурацией: свои объекты целиком (справочники `ПолучитьОбъект`, константы,
      регистры сведений — независимые одним набором, подчинённые — наборами по регистраторам), значения НОВЫХ
      реквизитов и ТЧ типовых объектов по ссылке, поля типовых регистров, уходящие в спутники (кейс 081 §5);
   2. `подготовить`: убрать из типовых регистров записи, которые без поля доработки станут неуникальными
      (у НПЦАП — строки цен с серией);
   3. `/LoadCfg` поставки, `/UpdateDBCfg`, загрузка расширения, первое обновление ИБ (кейс 081 §7);
   4. `загрузить` — в режиме `ОбменДанными.Загрузка` (проведённые остаются проведёнными, движения не трогаются).
2. **Значения — XDTO, ссылки сохраняют идентификаторы**: имена типов у объектов расширения те же, что были в
   конфигурации, поэтому `CatalogObject.дс_X` из старой базы читается как объект расширения с той же ссылкой.
   Через COM — английские имена: `cn.XDTOSerializer`, `cn.XMLTypeAssignment.Explicit`; `ЗаписьXML.УстановитьСтроку()`,
   `ЧтениеXML.УстановитьСтроку()` + `ПерейтиКСодержимому()`.
3. **Предопределённые своих справочников** расширение создаёт само со своими ссылками: перед записью перенесённого
   элемента удалить элемент с тем же `ИмяПредопределенныхДанных` и другой ссылкой (с `Загрузка`).
4. **Сверка — тем же снимком в режиме расширения** (поля спутников — из регистров-спутников), сравнение по ссылкам,
   не по порядку. Плюс отчёты доработок до/после на одних данных, плюс перепроведение нескольких документов уже в
   расширении: регистр-спутник совпадает с перенесённым. Итог НПЦАП: расхождений 0 (3.0.8.1 и 3.0.25.3).
5. **COM без глобального контекста**: `ТипЗнч` нет — тип параметра СКД брать из `Схема.Параметры[i].ТипЗначения`;
   коллекции метаданных — `.Найти(имя)`, не `[имя]`; режим записи регистра — из XML выгрузки.
6. **Отчёты, обрезающие период текущим моментом** (КТГ), сверять с концом периода в прошлом — иначе разница
   в последнем месяце зависит от времени запуска. Отчёты с параметром-ссылкой без значения по умолчанию (график
   работы) — подставлять первый элемент справочника; ошибка «в обеих базах одинаково» — тоже результат сверки.
