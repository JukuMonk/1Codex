# Уроки

**Симптом.** «Преобразование значения к типу Число не может быть выполнено» — только в бою, на первой строке с данными; форма АРМ не открывалась.

**Почему.** `Номер + ". "` пытается превратить `". "` в число: тип результата задаёт ЛЕВЫЙ операнд. `"…" + Число` безопасно.

**Что изменилось.** Число слева оборачивается `Строка()` или `Формат(…, "ЧГ=")`. `tools/check_bsl.py`: переменная, которой в процедуре присвоено число, стоит первой перед строковым литералом.

**Коммиты.** MVM d2415dd.

**Ссылки.** `knowledge/bsl.md` §3.
