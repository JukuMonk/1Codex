# Уроки (HIGH — проверено в платформе 8.5.1, тонкий клиент, ФРЕГАТ EAM, 26.10.2026)

1. **Поле HTML 1С рисует SVG-градиенты чёрным.** ECharts с `renderer: 'svg'` превращает
   `new echarts.graphic.LinearGradient(…)` в `<linearGradient>` + `fill="url(#…)"`; встроенный браузер 1С ссылку
   не разрешает и заливает чёрным (`fill` по умолчанию). Так же ломается `lineStyle.color: 'gradient'` у санки —
   связи серые. Edge (и headless Edge) рисует правильно, поэтому проверка только в браузере это не ловит.
2. **Что работает:** сплошной цвет `#RRGGBB`, `rgba(…)` и свойство `opacity` у `areaStyle`/`itemStyle`/`lineStyle`
   (полупрозрачные зоны на «Рисках» с `opacity: 0.13` рисовались верно). Площадь под линией:
   `areaStyle: { color: '#1F4E79', opacity: 0.14 }`; столбцы — средний цвет бывшего градиента; связи санки —
   `color: 'source'`. CSS `linear-gradient` фона страницы (шапка) в поле работает — не путать с SVG.
3. **Перед встраиванием страницы в поле HTML** искать в ней `LinearGradient`, `RadialGradient`, `'gradient'`,
   `url(#` в SVG и заменять сплошными цветами. Проверка — только снимок окна клиента 1С, не браузера.
4. Правка затронула лишь макет страницы: в тестовую базу с демо-данными достаточно скопировать `Template.bin`
   из проекта EDT в XML-выгрузку и `/LoadConfigFromFiles` + `/UpdateDBCfg` (как в case 102, без пересоздания базы).
   Первый запуск клиента после служебного может восстановить последнее открытое окно — снимок переснять.
