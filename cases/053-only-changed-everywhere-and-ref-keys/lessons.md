# Уроки

**Симптом.** После рамок (case 052) запись всё ещё 6 с: верхние строки профиля — `ПолучитьОбъект()` и `Записать()` по 69 раз (все геозоны), 68 тыс. проверок рамок. После первой правки профиль НЕ сдвинулся.

**Почему.** Узлы и проезды сравнивались с базой (case 051), а все 69 зон по-прежнему переписывались, и привязка считалась по всему графу. Первая правка не помогла, потому что помощник `ЗначениеПоКлючу` ищет по `Строка(Ключ)` — для ссылки это представление, а соответствие было сложено ПО ССЫЛКЕ: контур каждой зоны из базы выходил пустым, и все зоны считались изменёнными.

**Что изменилось.** Зоны сравниваются одним пакетом запросов (шапка, контур, типы ТС, техника; `ЗоныДляСравнения`, `ЗонаНеИзменилась`); пересчёт привязки получает списки изменённых узлов и проездов (записанные, помеченные, проезды у сдвинутых узлов) и заменяет в регистре строки только этих элементов набором с отбором по измерению `Элемент`; полный пересчёт — только когда изменилась зона. Ключи-ссылки читаются `Соответствие[Ссылка]`. Итог: 6 с → 1,5 с.

**Коммиты.** MVM 8db6ac6, c712e32.

**Ссылки.** `knowledge/bsl.md` §5, §9; cases 051, 052.
