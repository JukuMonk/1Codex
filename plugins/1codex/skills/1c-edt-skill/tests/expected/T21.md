    fields=[('Элемент', 'Элемент'), ('Тип', 'Тип'), ('Состояние', 'Состояние'), ('Элементов', 'Элементов')],
    query=…, selection=['Элемент', 'Тип', 'Состояние'],
    filters=[('Тип', 'Перечисление.ПримерПеречисление.ПустаяСсылка'), ('Состояние', '')],

Признаки:

- `.mdo`: `<defaultForm>CommonForm.ФормаОтчета</defaultForm>`,
  `defaultSettingsForm`, `defaultVariantForm` — типовые формы БСП;
  `<mainDataCompositionSchema>Report.ТестЭлементыПоТипу.Template.ОсновнаяСхемаКомпоновкиДанных</mainDataCompositionSchema>`;
  `<templates>` с именем схемы;
- `Template.dcs` (табы, CRLF): отбор `Тип` — `<dcsset:right xsi:type="dcscor:DesignTimeValue">Перечисление.ПримерПеречисление.ПустаяСсылка</dcsset:right>`;
  отбор `Состояние` — `<dcsset:right xsi:type="xs:string"/>` (case 034);
  оба `use false`, `viewMode QuickAccess`, `userSettingID` = uuid5;
  структура: группировка `Тип` + вложенная пустая `StructureItemGroup`
  (case 035);
- запрос: `ВЫБРАТЬ РАЗРЕШЕННЫЕ`, без `ЭтоГруппа` (справочник плоский — у
  плоского поля нет, case 017), экранирование `&`/`<`/`>` в XML;
- регистрация в `<reports>`, подсистема `ПримерГруппа` (`content` +
  `Report.ТестЭлементыПоТипу.Command.Открыть`), роль `Use`/`View`;
- `check_project` 0; отчёт: формирование в базе не проверялось.
