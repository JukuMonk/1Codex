# Уроки

**Симптом.** Кнопки карточки геозоны на плане не нажимаются в 1С (в браузере работают). После `confirm` щелчок доходил до строки списка под кнопкой (открывалась карточка зоны), и план зависал.

**Почему.** Диалог `confirm` модальный: движок ждёт ответа, очередь моста и таймеры копятся, после «ОК» событие уходит в элемент под курсором. Обработчики на элементы попапа Leaflet, навешанные через `setTimeout`, в поле 1С не срабатывали.

**Что изменилось.** Вопросы задаёт своя неблокирующая плашка `спросить(текст, приДа, кнопка)`; щелчки по кнопкам попапа ловятся делегированием на `document` по id кнопки.

**Коммиты.** MVM 9cf4094.
