# «Все реквизиты» подтягивает не все: повторяющийся ключ в таблице-источнике

**Проект и платформа.** «ФРЕГАТ: управление проектами» (UP), своя конфигурация без EDT, 8.5.1.1529; ДиЗ-07 к ТЗ-01,
18.10.2026.

**Замечание заказчика.** Справочник «Сценарии работы», кнопка «Черновик из версии структуры» → «Все реквизиты
версии» — «подтянул не все, а только часть». То же в версии-маппинге: «Загрузить все реквизиты принимающего объекта»
загружает только часть.

**Причина.** Версия структуры «Обработка АРМ Групповая загрузка ОР, ТОР…» — 60 строк, но 44 разных реквизита: один и
тот же реквизит стоит в шапке и в табличных частях «ГРУППОВАЯ ОБРАБОТКА ОР» и «… ТОР». Защита от повторного
заполнения проверяла «такой реквизит уже есть в шагах» — и вторая, третья строка того же реквизита отбрасывались
уже ВНУТРИ одного заполнения (−16 строк). На тестовых данных (все реквизиты разные) ошибка не видна.

**Сделано.** `after/ЗаполнитьИзВерсии.bsl`: защита по количеству — до заполнения посчитать, сколько раз каждый ключ
уже есть в приёмнике; при заполнении пропускать строку источника, только пока счётчик ключа > 0 (и уменьшать его).
Ключ — с табличной частью источника (в маппинге добавлены колонки «Табл. часть» передающей и принимающей стороны —
иначе одноимённые строки не различить). Подбор реквизита при вводе — реквизит один раз, в скобках все места:
«Родитель (шапка, ГРУППОВАЯ ОБРАБОТКА ОР)». Проверено нажатиями в песочнице: 60 из 60 строк, повторное заполнение
ничего не задваивает.
