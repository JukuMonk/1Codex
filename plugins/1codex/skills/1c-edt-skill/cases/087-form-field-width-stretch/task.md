# Поля формы: наименование узкое, а «узкое» поле растянуто на треть формы

**Объекты.** Формы элементов справочников, собранные `edt_lib.field` / `usual_group` / `object_tabular_table`.

**Проект: UP, EDT 2026.1, платформа 8.5.1.1529, тонкий клиент, Такси, формы открываются диалогами
(`clientApplicationWindowsOpenVariant = OpenDataInDialogs`).**

**Симптомы (снимки тонкого клиента).**
- Поле без `width` (наименование, многострочное «Описание», «Доработки») узкое, не тянется по ширине формы.
- Поле с `width=8` («Вход/выход») в горизонтальной группе занимает треть формы.
- Таблица табличной части с 11 колонками заданной ширины показывает 5, окно-диалог узкое.

**Причина.** `field` писал `autoMaxWidth=true` всем полям без ширины — платформа ограничивает их
«автоматической максимальной шириной»; у полей с шириной не было `horizontalStretch=false`, и в
горизонтальной группе они растягивались. Диалог берёт ширину по самой широкой строке полей.

**Результат.** `edt_lib.field(..., stretch=True)` — без `autoMaxWidth`, с `horizontalStretch=true` (тянется);
`stretch=False` — `horizontalStretch=false` (ширина держится); `object_tabular_table(..., max_width=False)` —
таблица без ограничения ширины. Наименования и тексты тянутся, узкие поля держат ширину.
