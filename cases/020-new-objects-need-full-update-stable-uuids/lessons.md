# Уроки

**Симптом.** «Ошибка добавления объекта DataProcessor uuid=… : нельзя
добавлять объекты метаданных без загрузки родительского объекта».

**Почему.** Инкрементальная загрузка умеет менять существующие объекты, но
не добавлять новые. Не про формы и не про uuid.

**Что изменилось.** Первое обновление после появления новых объектов —
полное; дальше снова инкрементальное. Генераторы берут uuid из существующего
файла, а для нового объекта — `uuid5` от имени: случайный uuid при
пересборке делал объект «новым» каждый раз, и база снова требовала полной
загрузки. Пробные объекты удалены.

**Коммиты.** MVM 3a6817e, c464d4f.
