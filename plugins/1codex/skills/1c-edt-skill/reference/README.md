# reference

Копии рабочих объектов проекта-источника (без изменений, с реальными
именами `мвм*`) и документы. Указатель «что искать для чего» — `INDEX.md`.

Правила обращения:

- это ОБРАЗЦЫ структуры, не заготовки: копировать структуру (порядок тегов,
  состав свойств, скелет элемента), а не файл с чужими uuid и именами — для
  заготовок есть `examples/` и `tools/scaffold.py`;
- uuid здесь реальные; в новый проект их переносить нельзя (объект с чужим
  uuid = «переименование» чужого объекта);
- версия платформы/метаданных источника — 8.3.24 / ТЛЭиУА 1.1.36; при
  другой версии сверять с типовым объектом целевой конфигурации;
- предметные подробности (логистика, карта) — контекст, не правило.

Генераторы в `generators/` содержат пути и имена проекта-источника; они
демонстрируют технику и без переписывания путей не запустятся.
