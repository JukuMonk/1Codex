# Уроки

**Симптом.** На `appReady` — «Строка, не закрывающаяся кавычкой»; упала
сборка ВСЕГО пакета, АРМ открылся пустым: ни заявок, ни рейсов, ни парка.

**Почему.** Текст запроса живёт внутри строкового литерала BSL: `<> ""`
закрыл литерал на первой кавычке. Пустая строка внутри запроса — четыре
кавычки `<> """"`.

**Что изменилось.** Условие убрано, пустые номера отсеиваются в коде
`ПустаяСтрока(...)`. Проверка: каждая строка запроса разворачивается («""» →
«"») и проверяется на чётность кавычек; конкатенация `" + Имя + "` пропускается.

**Правило.** Со строкой в запросе не сравнивать — отсеять в коде.

**Коммиты.** MVM 912f881; EDT 4416a94a.
