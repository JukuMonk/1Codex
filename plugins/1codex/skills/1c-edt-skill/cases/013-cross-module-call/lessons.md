# Уроки

**Симптом.** «{ОбщийМодуль.мвмМаршрутизация.Модуль(351,9)}: Процедура или
функция с указанным именем не определена (ЧислоИлиНоль)» при расчёте.

**Почему.** Компилятор общий модуль не проверяет, пока его не выполнят;
функция модуля формы общему модулю не видна.

**Что изменилось.** Помощник заведён в самой маршрутизации; инструмент ищет
имена, объявленные в одном нашем модуле и вызванные без префикса в другом.

**Правило.** Общий модуль самодостаточен: мелкие помощники — свои в каждом
модуле, а не через экспорт.

**Коммиты.** MVM 3b2973f; EDT eaf91043.

**Ссылки.** `examples/metadata/common-module/`, `tools/check_bsl.py`.
