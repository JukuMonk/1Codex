# Тонкий клиент падает при закрытии формы: группа и поле с одним именем

**Объекты.** Форма элемента справочника, собранная генератором (`edt_lib.usual_group` + `edt_lib.field`):
горизонтальная группа «строка формы» и поле внутри неё.

**Проект: UP (своя конфигурация «ФРЕГАТ: управление проектами»), EDT 2026.1, платформа 8.5.1.1529,
совместимость 8.5.1, тонкий клиент.**

**Симптомы.**
- Форма открывается и выглядит нормально, но закрытие длится минуты, затем тонкий клиент исчезает.
- В журнале Windows: `Faulting application name: 1cv8c.exe … Faulting module name: mngui.dll … Exception code: 0xc0000005`.
- Vanessa: «Ошибка сетевого взаимодействия при вызове» на следующем шаге (клиент тестирования умер).
- EDT ошибок не показывает, `check_project` (до правки) молчал, конфигурация грузится в базу без замечаний.

**Причина.** В форме два элемента с именем `Проект`: группа-строка `usual_group(ids, 'Проект', …)` и поле
`field(ids, 'Проект', 'Объект.Проект', …)`, и у обоих спутник `ПроектРасширеннаяПодсказка`. Имена элементов
формы обязаны быть уникальны; платформа это не проверяет при загрузке и падает в отрисовке.

**Результат.** Группа переименована (`ПроектПроцесс`), клиент закрывает форму мгновенно. В `edt_lib.check_form`
добавлена проверка повторяющихся имён элементов (items, extendedTooltip, contextMenu, autoCommandBar);
генератор форм UP прогоняет `check_form` для каждой формы и не пишет форму с претензиями.
