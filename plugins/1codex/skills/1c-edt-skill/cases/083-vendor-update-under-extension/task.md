# Обновление поставки под расширением доработок: трёхстороннее слияние, ошибки поставщика при скачке версий

**Проект и платформа.** НПЦАП (`C:\gold\NPCAP`): 1С:ТОИР КОРП 3.0.8.1 → **3.0.25.3** (совместимость 8.3.21 → 8.3.25),
расширение `НПЦАП_Доработки` (кейсы 081–082), платформа 8.3.27.2342, БСП. Октябрь 2026.

**Задача.** Основная конфигурация — новая поставка без изменений; расширение пересобрать под неё; рабочую базу
(демокопию) перевести с доработанной 3.0.8.1 на 3.0.25.3 + расширение с сохранением данных.

**Что пошло не так.**
1. Из 75 перехваченных методов 36 поставщик изменил, 1 удалил (`ПодготовитьТаблицуТрудовыхЗатрат`), отчёт КТГ
   переименовал (`торо_КТГОборудования` → `торо_КТГОбъектовРемонта`); схемы СКД, которые Деснол замещал целиком,
   поставщик тоже менял.
2. `git merge-file` дал конфликты там, где обе стороны лишь ВСТАВИЛИ строки в одно место, и там, где разница — концевые
   пробелы.
3. Режим 8.3.25 тоже не позволил добавить поля в заимствованные регистры («… недопустимо в режиме совместимости
   8.3.25 и ниже») — спутники остались.
4. Обновление ИБ 3.0.8.1 → 3.0.25.3: `{ОбщийМодуль.торо_ОбновлениеИнформационнойБазы.Модуль(4921)}: Поле объекта не
   обнаружено (торо_НастройкиУведомлений)` — обработчик версии 3.0.13.1 в коде 3.0.25.3 ссылается на регистр,
   переименованный позже в `Удалитьторо_НастройкиУведомлений`; падает в блоке `Исключение`, исходная ошибка теряется.
5. Собственные объекты Деснол (отчёты, печать) на 3.0.25.3: «Таблица не найдена Справочник.торо_СписокОбъектов…»,
   «…НаработкаОбъектовРемонта.Остатки», «Поле не найдено …СписокОбъектовРемонта», «Поле объекта не обнаружено
   (ДатаКонца)» — поставщик переименовал объекты (uuid те же), сделал регистр оборотным, переименовал ключ параметров.
   `CheckModules` этого не видит.
6. Отчёты ТОИР 3.0.25.3 через COM: «Поле объекта не обнаружено (КлючПредопределенногоВарианта)».
7. Тестовый клиент проверки форм (`/C ПроверкаФорм`) на обновлённой базе молча стоял: окно БСП «Я подтверждаю
   легальность получения обновления» до `ПослеНачалаРаботыСистемы`.
