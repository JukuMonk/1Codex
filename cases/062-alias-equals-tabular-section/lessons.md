# Уроки

**Симптом.** При открытии отчёта: «{(57, 6)}: Неоднозначное поле "Тарировка.Ссылка" ПО <<?>>Тарировка.Ссылка = Датчики.Ссылка». Проверка полей и псевдонимов молчала.

**Почему.** Подзапрос по табличной части `Справочник.X.Тарировка` получил псевдоним `Тарировка`, а у основной таблицы `Датчики` есть ТЧ с тем же именем: для платформы `Тарировка.Ссылка` — и поле таблицы-псевдонима, и обращение к ТЧ через таблицу запроса.

**Что изменилось.** Псевдоним переименован в `ТочкиТарировки`; проверка запросов сверяет псевдонимы источников и подзапросов с именами ТЧ всех объектов запроса.

**Коммиты.** MVM (отчёт мвмДатчикиТоплива, запросы_1с.py).

**Ссылки.** `knowledge/bsl.md` §4; case 016.
