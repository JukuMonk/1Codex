# Мобильная форма — ПримерМобильная / ФормаМобильная

**Что демонстрирует.** Обработка с формой на два назначения
(`<usePurposes>MobileDevice</usePurposes>` и `PersonalComputer` у формы в
.mdo — одна форма и для телефона, и для тонкого клиента; у КОРНЯ
конфигурации при этом обязан быть `MobileDevice` — case 005). Экран:
`Pages` с `TabsOnTop` (case 030) и тремя страницами — «Сейчас» (надпись
что делать жирным, поля только чтение, кнопки на странице `Дальше`
(главная, синяя) и `НеПолучается` (осторожно)), «Задачи» (таблица значений
только чтения: `commandBarLocation None`, строка поиска/состояние/управление
поиском `None`, три текстовые колонки, без булевых — case 041, контекстное
меню строки вместо смахивания), «Чат» (таблица сообщений, поле ввода,
кнопка «Отправить»). Модуль: `ПриСозданииНаСервере` заполняет экран одной
серверной функцией, обработчик ожидания обновляет, команды — клиент →
сервер. HIGH — сборка АРМ водителя (`reference/DataProcessors/мвмМоиРейсы`).

**Обязательные файлы.**

```
ПримерМобильная/ПримерМобильная.mdo
ПримерМобильная/Forms/ФормаМобильная/Form.form
ПримерМобильная/Forms/ФормаМобильная/Module.bsl
```

Плюс в Configuration.mdo корня — `MobileDevice`; в роли для мобильного
пользователя — право `MobileClient` (`metadata/role`).

**Что можно менять.** Состав страниц (`edt_lib.pages`/`page`), поля и
кнопки (`page_button` со стилем `обычная`/`главная`/`осторожно`), таблицы
(`value_table(mobile=True)`), `pagesRepresentation Swipe` для «листания»
на телефоне (на компьютере тогда между страницами не перейти). Числовые
реквизиты формы — только с `numberQualifiers` (case 001; без них пустой
лист, который четыре часа объясняли «мобильностью» — case 006).

**Что согласовано.** Имя реквизита-объекта `ТекущийОбъект` (не «Объект»
— занято формой, case 010); колонки реквизитов-таблиц ↔ колонки элементов;
команды ↔ процедуры модуля.

**Похожее.** `knowledge/mobile-forms.md`; cases 005, 006, 030, 041;
`reference/generators/проба_мобильной_формы.py` (лесенка проб).
