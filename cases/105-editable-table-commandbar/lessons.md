# Симптом → причина → правило

В табличной части нет «Добавить». Проверка COM и открытие формы проходят.
Причина: `Form.table` по умолчанию создаёт `ChangeRowSet=false`, а у панели — `Autofill=false`.
Для таблицы пользовательского ввода явно задавать `change_rowset=True, autofill=True`.
Для существующей формы убрать запрет изменения строк и включить автозаполнение стандартной панели.
Одного автозаполнения недостаточно, если изменение состава строк по-прежнему запрещено.

Глобальные умолчания построителя не менять: таблицы результатов и фиксированных настроек могут полагаться на них.
Проверка редактируемой ТЧ должна включать штатное добавление строки, выбор значения, запись и повторное открытие.
COM не проверяет доступность действий для пользователя. На итоговом снимке отдельно проверить командную панель.
