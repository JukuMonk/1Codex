# T02 — реквизит в существующий объект

Решение:

```python
text = L.read_text(mdo_path)
text = L.add_attributes_to_mdo(text, [('Описание', 'Описание', 'Строка(0)')])          # шапка
text = L.add_attributes_to_mdo(text, [('Подпись', 'Подпись', 'Строка(50)')], in_ts='Точки')  # ТЧ
```

Обязательные утверждения в отчёте:

- 2000 > 1024 → обновление базы падает «Ошибка SDBL: слишком большое
  значение описателя длины» (case 024); заведена неограниченная длина
  (`<stringQualifiers/>` без `<length>`), как делает типовая в 1876 местах;
  либо длина 1024 — если ТЗ допускает усечение (сказать об этом);
- реквизит ТЧ — без `fillValue` (case 025); порядок тегов
  `minValue → maxValue → fillChecking → fillValue → fullTextSearch → dataHistory`;
- якорь вставки — `\r\n  </attributes>\r\n` (с отступом): голый `</attributes>`
  совпадает и с закрытием реквизита ТЧ (отступ 4) — реквизит уехал бы внутрь ТЧ;
- на форме: `L.field(ids, 'Описание', 'Объект.Описание', 4, multiline=True)`
  в группу «Прочее»; номер — следующий из счётчика ЭЛЕМЕНТОВ (взять
  максимальный `<id>` среди элементов формы + 1), не из реквизитов;
- существующий объект → инкрементальное обновление достаточно (case 020).

Проверка: `check_project` 0 ошибок; `git diff` показывает только вставленные блоки.
