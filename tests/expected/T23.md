# T23 — раздел с группами

По `metadata()` в `tools/make_examples.py` (подсистема с дочерней и картинкой):

```python
L.subsystem_mdo('ТестРаздел', 'Тест', [], children=['ТестСправочники', 'ТестОтчёты'], picture='ТестРаздел')
L.command_interface_cmi(subsystems=['ТестСправочники', 'ТестОтчёты'], parent='ТестРаздел')
L.subsystem_mdo('ТестСправочники', 'Справочники', ['Catalog.ПримерСправочник', 'InformationRegister.ПримерНедоступность'], parent='ТестРаздел')
L.subsystem_mdo('ТестОтчёты', 'Отчёты', ['Report.ПримерОтчет', 'Report.ПримерОтчетПоПериоду'], parent='ТестРаздел')
L.common_picture_mdo('ТестРаздел', 'Раздел "Тест"'); make_picture(...)   # Pillow
register_in_configuration(config, 'Subsystem', 'ТестРаздел'); register_in_configuration(config, 'CommonPicture', 'ТестРаздел')
```

Признаки:

- `Subsystems/ТестРаздел/ТестРаздел.mdo`: `<subsystems>ТестСправочники</subsystems>`
  (КОРОТКИЕ имена), `<picture>CommonPicture.ТестРаздел</picture>`;
- `Subsystems/ТестРаздел/Subsystems/ТестСправочники/ТестСправочники.mdo`:
  `<parentSubsystem>Subsystem.ТестРаздел</parentSubsystem>` — без него EDT
  дочерней не считает: «нельзя добавлять объекты без загрузки родительского
  объекта» / «Файл объекта не существует» (case 019);
- `CommandInterface.cmi` раздела: `subsystemsOrder` с
  `Subsystem.ТестРаздел.Subsystem.ТестСправочники`; у групп — команды объектов
  (`Catalog.X` — список, `Report.X.Command.Открыть`);
- `Configuration.mdo`: только `Subsystem.ТестРаздел` и
  `CommonPicture.ТестРаздел` (по алфавиту среди картинок) — case 021;
- uuid раздела ≠ uuid картинки (разные seed);
- `Picture.zip`: 85/100/125/150/175/200/300/400.png + Picture.png +
  manifest.xml с BOM (case 040) — или явное «Pillow не установлен, zip не
  собран, состав такой-то»;
- отчёт: новые подсистемы — полное обновление базы (case 020).
