# Несколько видов графа на ECharts в поле HTML внешней обработки: встраивание библиотеки в макет, подсказка после setOption, headless Edge

**Объекты.** Форма «Граф потоков» внешней обработки «АЗОТ Анализ потерь материальных потоков». В поле HTML пять видов одной модели: слои (своё SVG), а также санки, матрица связей (heatmap), дерево причин (tree) и сеть (graph) на Apache ECharts 5.6.0. Библиотека встроена в текстовый макет, интернета не нужно.

**Проект: КАО АЗОТ (1С:ТОИР КОРП 3.0.8.1, платформа 8.3.27, тонкий клиент, без EDT).**

**Что пошло не так.**
1. После щелчка по клетке или узлу ECharts вид перерисовывался через `setOption(опции, true)` (notMerge), и страница ловила `Cannot set properties of null (setting 'innerHTML')` внутри библиотеки. Подсказка пересоздаётся, а её отложенный показ пишет в удалённый элемент.
2. Headless Edge (`--dump-dom`, `--screenshot`), запущенный из инструмента Bash (Git Bash), молча отдавал пустой вывод с кодом 0, даже для `about:blank`. Тот же Python из PowerShell работает.
3. Python-скрипт с заменами, переданный через heredoc в Bash, записал в генератор вместо `'\r\n'` настоящие переводы строк, а вместо `'\x01'` — управляющий символ: обратные косые черты «съелись». Генератор перестал разбираться (SyntaxError).
4. Шестой вид — Cytoscape.js 3.34.3 + dagre (блоки рамками) — в Edge работал, а в тонком клиенте падал трижды подряд: нет `getRootNode`, потом `structuredClone`, потом `matchAll`.

**Результат.**
- ECharts целиком (1 МБ, ES5) лежит в макете; строки длиннее 900 символов разрезаны с маркером `Символ(1)`.
- `ГрафHTML()` склеивает макет обратно; через COM проверено, что результат совпадает с исходной страницей один в один.
- В тонком клиенте все пять видов на ECharts нарисованы без ошибок, каждый за 70–870 мс; сеть с силовой раскладкой — самая медленная.
- После замен трёх функций в раннем скрипте работает и Cytoscape: раскладка dagre с рамками блоков — 2,7 с, щелчки (выбор, свёртка, развёртка) проверены.
- Мост страница → 1С не сломан: сценарий UI с автотестом дал «Изменения (1)».

**Confidence:** HIGH (8.3.27, тонкий клиент; Edge 154 headless).
