# Уроки

**Симптом.** Кэш «находил» отрицательный ответ ещё до первого расчёта, и
маршрут не строился никогда: «Пути нет (по данным кэша)» между соседними узлами.

**Почему.** `РегистрыСведений.X.Получить(Отбор)` возвращает структуру с
ПУСТЫМИ ресурсами, если записи нет; `Неопределено` — никогда. Проверка
`Запись = Неопределено` не срабатывала, а `Найден = Ложь` читался как ответ.

**Что изменилось.** Факт наличия записи — запросом `ВЫБРАТЬ ПЕРВЫЕ 1`;
`Получить` оставлен только там, где пустое значение и отсутствие записи
означают одно и то же (настройки).

**Коммиты.** MVM 904fc5e; EDT b5bf86f1.
