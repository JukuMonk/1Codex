# COM-проверки из Python: нет `Формат`/`Строка`/`ТекущаяДата`; серверные процедуры формы не вызвать; `НайтиПоНомеру` без даты пуст

**Проект и платформа.** МВМ — «Заводская логистика» на типовой 1С:ТЛЭиУА КОРП (УАТ) 1.1.36.1, проект EDT, копии базы
под 8.3.27.2342 (`V83.COMConnector`, pywin32); ДиЗ-04 и ДиЗ-05 к ТЗ-08, 08–09.10.2026.

**Задача.** Проверка ДиЗ на копии базы ПСИ через COM: подготовить данные (снять листы заказов 30, 31), прочитать
результат раздачи, распечатать время рейсов в отчёт «12.10 15:26».

**Что пошло не так.**
1. `cn.Формат(Дата, "ДФ=…")`, `cn.Строка(…)`, `cn.ТекущаяДата()` — `AttributeError`: у соединения этих
   глобальных функций нет. Есть `cn.String`, `cn.XMLString`, `cn.XMLValue` (английские имена) и `cn.NewObject`.
2. Раздачу (`АвтоНазначить`, `СоздатьМаршрутныйЛист` — `&НаСервере` в модуле формы обработки) через COM не вызвать:
   у формы нет объекта на стороне соединения. Доступны только экспортные функции общих модулей и модулей менеджеров.
3. `Документы.уатЗаказГрузоотправителя.НайтиПоНомеру("00000000031")` вернул пустую ссылку, хотя заказ есть: номер
   уникален в пределах года (`numberPeriodicity` Year), без даты интервала документ не нашёлся.

**Итог.** Дату печатать через `cn.XMLString(дата)` и резать строку (`гггг-мм-ддTчч:мм:сс`); вызывать только
экспортные функции общих модулей, а действия формы — шагом Vanessa, проверяя данные COM после прогона; документ
по номеру искать запросом (`ГДЕ Номер = &Н УПОРЯДОЧИТЬ ПО Дата УБЫВ`) или `НайтиПоНомеру(Номер, Дата)`.
