# T09 — панель поиска над списком

Форма: перед таблицей `Список` (и после группы настроек) — группа
`ПанельПоиска` `AlwaysHorizontal` с `verticalStretch=False`
(`L.usual_group(..., vertical_stretch=False)`; без него панель делит высоту
с таблицей — case 009); поля `ПоискТип`, `ПоискНаименование` с обработчиками
`OnChange`, ширины с `autoMaxWidth`. Реквизиты `ПоискТип :
EnumRef.ПримерПеречисление`, `ПоискНаименование : String` получают номера
после `Список` (одно пространство с колонками — case 003).

Модуль — по `examples/bsl/dynamic-list-filter.bsl`:

- `&НаКлиенте ПоискТипПриИзменении(Элемент)` → `ПрименитьОтбор()`;
- `&НаКлиенте ПрименитьОтбор()` и `&НаСервере ПрименитьОтборНаСервере()` с
  одним телом (case 033), отбор через
  `ОтборыСписковКлиентСервер.ИзменитьЭлементОтбораСписка(Список, "Тип", ПоискТип, ЗначениеЗаполнено(ПоискТип))`
  и `…("Наименование", ПоискНаименование, НЕ ПустаяСтрока(…), ВидСравненияКомпоновкиДанных.Содержит)`;
- при отборе иерархический список показывать плоско (`Отображение =
  ОтображениеТаблицы.Список`, `ЭтоГруппа = Ложь`) — для плоского справочника
  этот шаг не нужен, но не вредит.

Признаки: `check_project` 0; обработчики из `<handlers>` есть в модуле с
`&НаКлиенте`; `Параметры` не занято.
