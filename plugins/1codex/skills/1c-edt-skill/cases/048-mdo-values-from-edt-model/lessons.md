# Уроки

**Симптом.** Кэш графа «не работает»: второй серверный профиль показал те же 91 чтение справочников, что и до кэша. EDT ошибки не показал, модуль обновился в базе.

**Почему.** В `.mdo` было написано `DuringCall` — такого значения в модели EDT нет. EDT принял файл МОЛЧА и выгрузил модуль без повторного использования. Существуют `DuringRequest` («на время вызова») и `DuringSession` («на время сеанса»).

**Что изменилось.** Значение взято из `grep -r returnValuesReuse src/CommonModules` типовой (8 DuringRequest, 4 DuringSession); генератор проверяет значение по списку допустимых. Для графа завода выбран `DuringSession` со сбросом `ОбновитьПовторноИспользуемыеЗначения()` при записи карты: «на время вызова» оставляло чтение графа на каждый серверный вызов.

**Коммиты.** MVM db9c575 (DuringRequest), ebe2fa1 (DuringSession).
