# Уроки

**Чужая библиотека в текстовом макете (Конфигуратор, без EDT).**
- В странице стоит метка `<script>/*ECHARTS*/</script>`. Генератор вставляет на её место минифицированный файл и режет строки длиннее 900 символов. Режет только маркером: в конце куска ставится `chr(1)`, затем CRLF. Готовый текст пишется в `Templates/<Макет>/Ext/Template.txt` (BOM, CRLF).
- Модуль склеивает обратно: `СтрЗаменить(Текст, Символ(1) + Символы.ВК + Символы.ПС, "")`, затем то же для `Символ(1) + Символы.ПС`, затем для одиночного `Символ(1)`.
- Генератор проверяет, что разрез обратим, и что в библиотеке нет ни маркера, ни `</script`.
- Через COM сравнить `ГрафHTML()` со страницей — так проверяется вся цепочка: сборка .epf, хранение макета, склейка.

**ECharts в поле HTML 1С (8.3.27).**
- До библиотеки заменить `requestAnimationFrame` таймером: zrender берёт функцию при загрузке, а кадры в окне 1С не гарантированы (ловушка МВМ).
- Ставить `animation: false` и `devicePixelRatio` не больше 1,5.
- Инициализировать график, когда его блок уже видим: при `display:none` размер нулевой.
- Для прокручиваемых видов (матрица, санки, дерево) размер задаётся явно по числу строк, листьев или слоёв.

**Cytoscape.js в поле HTML 1С 8.3.27: трёх функций нет.** WebKit поля по этим функциям старше Safari 13, хотя grid в нём есть.
- Ошибки по очереди: `e.getRootNode is not a function` при создании, `Can't find variable: structuredClone` в запасной раскладке, `v.matchAll is not a function` при переносе подписей.
- Лечится заменами в раннем скрипте, ДО библиотек:
  - `Node.prototype.getRootNode` — подъём по `parentNode`;
  - `structuredClone` — через JSON;
  - `String.prototype.matchAll` — массив совпадений из `exec`, с `lastIndex++` на пустом совпадении.
- Перед встраиванием чужой библиотеки прогнать по ней поиск современных API: `matchAll`, `structuredClone`, `getRootNode`, `flat`, `fromEntries`, `replaceAll`, `at(`, `?.`, `??`. Каждый найденный вызов закрыть заменой или проверить в тонком клиенте. Edge их все знает и ошибок не покажет.
- В dagre 0.8.5 разделитель ключа ребра — сам символ `\x01` в строке, а это маркер разреза макета. Заменить при сборке escape-записью, для JS значение то же.
- dagre с вложенными узлами (рамки блоков) и циклами ненадёжен. Обратные связи в раскладку не передавать (`eles.not('edge[?back]').layout(...)`), рисовать их поверх готовой раскладки.
- Событие `tap` всплывает от стадии к рамке-родителю. Обрабатывать по `e.target` один раз; рамка получает свой `tap`, только когда щёлкнули по ней самой.
- Время в тонком клиенте: dagre и отрисовка 60 узлов, 14 рамок и 138 связей — 2,7 с. ECharts-виды — 0,1–1 с.

**Перерисовка после щелчка.**
- Делать её после обработчика ECharts: `setTimeout(…, 0)`.
- Вызывать `setOption(опции, {replaceMerge: ['series']})`, а не `notMerge`. Иначе подсказка пересоздаётся, и её отложенный показ пишет в `null.innerHTML`.
- Состояние свёртки дерева (`collapsed`) хранить у себя: при каждом `setOption` оно приходит из данных.

**Проверка щелчков ECharts без человека.** zrender слушает pointer-события.
- Нажатие — это последовательность `pointermove`, `pointerdown`, `mousedown`, `pointerup`, `mouseup`, `click` на `firstChild` контейнера, в точке элемента.
- Точку брать так: `data.getItemGraphicEl(i)`, затем `transformCoordToGlobal` от центра `getBoundingRect()`.

**Headless Edge из Bash-инструмента пустой.** На Windows Server проверки страниц (`--dump-dom`, `--screenshot`) запускать из PowerShell: из Git Bash Edge молча ничего не выводит, код возврата при этом 0.

**Правки с обратной косой чертой — не через heredoc в Bash.** `'\r\n'` и `'\x01'` превратились в настоящие символы. Такие правки делать инструментом Edit или собирать строку через `chr(92)`, а после правки разбирать файл: `ast.parse`, сборка.

**Упрощение тяжёлого графа потоков.**
- Срезать «малые» связи по доле количества, как в Disco или Fuzzy Miner, нельзя: стадии нужен каждый вход.
- Работают другие приёмы:
  - общие сети (стадии с ≥N потребителями) заменить ярлыками у потребителей;
  - свернуть стадии по блокам и цехам с раскрытием щелчком;
  - матрица для плотных связей;
  - дерево от места учёта для поиска причин.
- На Ам-1 так связей стало вдвое меньше: 138 вместо 285.
