# Уроки

**Правило.** Имя группы — не имя поля: группам давать суффикс (`…Строка`, `…Группа`, `ПроектПроцесс`).
Имя элемента, совпадающее с основным реквизитом формы (`Объект`), тоже не брать: поле с путём
`Объект.Объект` называть `ОбъектКонфигурации` и т. п.

**Как искать.** Клиент 8.5.1 падает (`mngui.dll`, `0xc0000005`) при закрытии формы, а EDT и загрузка
конфигурации молчат → проверить уникальность имён элементов формы: `check_project` (с этого кейса) или
быстро: `grep -o "<name>[^<]*</name>"` по `items` формы, повторы с суффиксом `РасширеннаяПодсказка` — верный
признак.

**Проверка.** `edt_lib.check_form` — «повторяющиеся имена элементов формы». Генераторы форм: прогонять
`check_form` перед записью.

**Ссылки.** case 007 (свойства групп), case 003 (номера элементов); `knowledge/managed-forms.md`.
