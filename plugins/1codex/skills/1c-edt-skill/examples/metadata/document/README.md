# Документ — ПримерДокумент

**Что демонстрирует.** Документ с реквизитами шапки (`Объект` — ссылка с
проверкой заполнения, `Комментарий` — Строка(0)), табличной частью `Строки`
(Объект, Количество), движениями по регистру остатков (`registerRecords`,
`postingMode`), формой документа (`defaultObjectForm`). **MEDIUM**: свой
документ в проекте-источнике не заводился (заявка и рейс — типовые
документы), .mdo собран по типовому и проверен структурно; форма собрана
теми же скелетами, что и рабочие формы (HIGH по форме, кроме
`DocumentFormExtInfo`, у которого боевого эталона нет).

**Обязательные файлы.**

```
ПримерДокумент/ПримерДокумент.mdo
ПримерДокумент/Forms/ФормаДокумента/Form.form
```

Регистрация: `<documents>Document.ПримерДокумент</documents>`. Модуль
объекта с `ОбработкаПроведения` в примере не приведён (LOW) — писать по
типовому документу целевой конфигурации.

**Что можно менять.** Реквизиты и ТЧ (`edt_lib.document_mdo`), нумерация
(`numberLength`, `numberType`, `numberPeriodicity`), список регистров.
Форма: поля `Объект.Number`, `Объект.Date`, реквизиты — `Объект.Имя`, ТЧ —
`Объект.Строки` через `object_tabular_table`.

**Что согласовано.** uuid `stable_uid('Document/…')`; `CatalogRef.ПримерСправочник`
в шапке и ТЧ; `AccumulationRegister.ПримерОстатки` в движениях; отчёт
`ПримерОтчетПоПериоду` читает `Документ.ПримерДокумент`; ТЧ через ссылку не
читается — только запросом (`examples/bsl/query-patterns.bsl`).
