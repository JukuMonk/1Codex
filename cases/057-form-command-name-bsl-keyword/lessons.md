# Уроки

**Симптом.** «Ожидается имя процедуры» при открытии формы; EDT промолчал.

**Почему.** Команда `Прервать` даёт обработчик `Процедура Прервать(Команда)` — `Прервать` ключевое слово языка.

**Что изменилось.** Команда переименована в `ПрерватьРейс`; генератор форм проверяет имена команд по списку ключевых слов BSL (`Прервать, Продолжить, Возврат, Выполнить, Перейти, Если, Для, Пока, Новый…`); `tools/check_bsl.py` ловит объявление процедуры с таким именем.

**Коммиты.** MVM 2b7df65.

**Ссылки.** `knowledge/bsl.md` §2; `knowledge/managed-forms.md`.
