# Образцы проверок из ФРЕГАТ EAM (8.5.1)

Рабочие скрипты проекта EAM, пути к базе и проекту ЗАШИТЫ — брать как шаблон, не запускать как есть.
Общая часть вынесена в `tools/platform.py` (`forms`, `com fill`); здесь — то, что зависит от формы проекта:

- `platform_dash.py` — вставка в XML-копию: форма панели пишет собранную страницу (шаблон + данные) и пакет
  карточки в файлы; второй проход открывает вкладку страницы в клиенте (ждёт снятия заставки загрузки) и
  снимает окно (PrintWindow, DPI-aware).
- `dash_shots.py` — варианты страницы со вставленным скриптом (вкладка, фокус, объект, пакет карточки) →
  headless Edge (`--headless`, своя `--user-data-dir`, ожидание файла); `--fresh` — свежий шаблон к снятым данным.
- `platform_click.py` — вызов обработчика `ПриНажатии` формы со всеми действиями страницы (hex-параметры),
  итог «действие => ок / ошибка» через хранилище настроек.
- `audit_fill.py` — первая версия аудита заполненности (выборка 300 строк — см. testing.md §6, почему мало).

Подробно — `knowledge/testing.md` §5–8.
