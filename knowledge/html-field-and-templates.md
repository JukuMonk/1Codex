# Поле HTML, макеты и мост «страница ↔ 1С»

Здесь только то, что относится к платформе 1С и файлам EDT; сама страница
(JS) — за рамками. Пример — `examples/forms/html-field-form/`, эталон —
`reference/DataProcessors/мвмАРМДиспетчера/` (Form.form и
`Module.bridge-extract.bsl` — мост, отработавший в тонком клиенте).

## 1. Поле HTML на форме (HIGH)

```xml
<items xsi:type="form:FormField"> … <type>HTMLDocumentField</type> <editMode>Enter</editMode> …
  <extInfo xsi:type="form:HtmlFieldExtInfo">
    <handlers><event>DocumentComplete</event><name>ПолеКартыДокументСформирован</name></handlers>
    <width>70</width><autoMaxWidth>true</autoMaxWidth>
    <height>10</height><autoMaxHeight>true</autoMaxHeight>
    <horizontalStretch>true</horizontalStretch><verticalStretch>true</verticalStretch>
```

`width` и `height` обязательны ВМЕСТЕ с растяжением: без них документ
получает viewport нулевой высоты («окно:2711x0»), и страница с
`html,body{height:100%}` схлопывается — белый экран при живых скриптах
(case 022). Так стоит у обоих типовых АРМ конфигурации с полем HTML.
Реквизит — `HTMLСтраницы : String` без ограничения длины, поле привязано к
нему, а не к URL.

## 2. Макет со страницей (HIGH)

- Тип макета — **Текстовый документ** (или двоичные данные): макет «HTML
  документ» платформа может переформатировать.
- Текстовый макет хранится ПОСТРОЧНО: файл в LF 1С увидела ОДНОЙ строкой на
  458 тыс. символов и показала пустой экран — только CRLF (case 023).
- Очень длинных строк макет не переносит: во всей типовой максимум 2970
  символов, минифицированная библиотека — 147 363. Сборка режет строки по
  900 символов, помечая разрез `Символ(1)` В КОНЦЕ куска (если 1С обрежет
  хвостовые пробелы, обрезать будет нечего), модуль склеивает обратно
  (`examples/forms/html-field-form/…/Module.bsl`).
- Двоичный макет (`BinaryData`) EDT хранит сырым файлом: `Template.bin` —
  это и есть PNG, проверено побайтово. (Контейнер 1С внутри `Template.bin` у
  одного вендорского объекта — исключение.)
- Макет берётся у объекта: `РеквизитФормыВЗначение("Объект").ПолучитьМакет("Имя")`.

## 3. Мост без вызова JS (HIGH)

В связке «V8WebKit + тонкий клиент» вызывать функции страницы из 1С
ненадёжно; работает обмен через DOM-поля:

- **1С → страница**: 1С пишет текст в `<input id="in_<тип>">` и метку
  `длинаномер` в `in_<тип>_sig`; страница опрашивает поля таймером
  (`setInterval`, 40 мс), сверяет длину (порция могла не доехать) и номер.
  Разные поля на тип (`package`, `underlay`, `cmd`…), чтобы сообщения не
  затирали друг друга.
- **Страница → 1С**: очередь команд `[{n, k, d}]` JSON в `bridge_out`; 1С
  читает обработчиком ожидания раз в секунду (минимум для повторяющегося),
  обрабатывает только `n` больше последнего, пишет подтверждение в `out_ack`;
  страница по подтверждению чистит очередь. Крупные данные — из поля
  `bridge_data` с проверкой размера.
- Рукопожатие: страница шлёт `ready` при загрузке и `appReady`, когда
  поднялась целиком; данные слать только на `appReady`.
- `Элементы.Поле.Документ` доступен ТОЛЬКО после `ДокументСформирован`; на
  этот момент страница ещё может разбираться — осмотр отложить на секунды.
- Сбои JS страница пишет в поле `js_errors`; `value` поля 1С читает надёжно,
  свойства JS-объектов — как повезёт.

## 4. Поведение движка поля (HIGH, но про страницу)

- Пока идёт долгий серверный вызов, поле продолжает принимать клики;
  обработчики ожидания копятся. Пользователя выбрасывало из 1С. Лечение с
  двух сторон: страница на время записи закрывается шторкой, модуль отключает
  опрос моста и включает в `Попытка`.
- `requestAnimationFrame` в поле не гарантирован — периодику вести
  `setInterval`; canvas теряет содержимое — векторная графика SVG надёжнее;
  бесконечные CSS-анимации и `backdrop-filter` вешают форму; `gap` во
  флекс-контейнере не работает (движок возраста Safari 13); `localStorage`
  ненадёжен — постоянство хранить в 1С.
- `confirm()`/`alert()` в поле не использовать: диалог модальный, очередь
  моста и таймеры копятся, после «ОК» щелчок уходит в элемент под кнопкой,
  форма виснет. Своя неблокирующая плашка. Обработчики на элементы попапа
  через `setTimeout` в поле не навешиваются — делегирование на `document`
  по id кнопки (case 054).

## 5. Вторая форма на том же модуле (HIGH, `reference/DataProcessors/мвмАРМДиспетчера/Forms/ВыборПунктаНаКарте/Form.form`)

Форма выбора на плане: новая форма в той же обработке, модуль = модуль
основной формы + три правки (класс на `<body>` в макете через `СтрЗаменить`,
своя обработка команды `select`, область выбора), макет общий. Открывается
из документа с `ОписаниеОповещения` и `РежимОткрытияОкнаФормы.БлокироватьВесьИнтерфейс`,
результат — `Закрыть(Пункт)`. Обратная связь в форму — только командой
через очередь; обработчики ожидания в блокирующей форме работают.

## 6. Мост ссылкой и проверка без человека (HIGH, case 079)

Страница → 1С проще очереди §3: `<a href="#префикс-команда">` или программный `a.click()` по скрытой ссылке
даёт `ПриНажатии` с `ДанныеСобытия.Href` вида `e1c://filev/<путь базы>#префикс-…` и `Element` = ссылка
(8.3.27, тонкий клиент). Плитке-ссылке — `pointer-events:none` у детей. Команду брать после «#префикс-»,
`СтандартнаяОбработка = Ложь`. Проверка без человека: параметр запуска клиента `/C "…"` — форма кладёт команду
в скрытое поле, страница сама нажимает ссылку. Открытая из обработчика карточка — ОТДЕЛЬНОЕ окно: снимать все
окна процесса. ECharts: одна метка библиотеки (не в комментариях — заменяются все вхождения), `progressive: 0`
у серий с тысячами элементов (кадры у нас — таймер).
