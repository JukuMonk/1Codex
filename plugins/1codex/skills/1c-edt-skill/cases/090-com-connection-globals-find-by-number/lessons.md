# Уроки

**Глобальный контекст COM-соединения — не весь и не всегда по-русски.** Есть `String`, `XMLString`, `XMLValue`,
`NewObject`, менеджеры (`Документы`, `Справочники`, `РегистрыСведений`) и общие модули; `Формат`, `Строка`,
`ТекущаяДата` — нет (`AttributeError`, платформа 8.3.27). Дату печатать через `cn.XMLString` и срез строки; дату
В 1С передавать не «наивным» `datetime` (pywin32 сдвигает на пояс, case 078), а значением, прочитанным из 1С, или
`XMLValue`.

**Серверные процедуры формы через COM не вызываются.** Вызываемо только экспортное: общие модули, модули
менеджеров, методы объектов. Логику, которую нужно проверять через COM, держать в общем модуле
(`&НаСервереБезКонтекста` → общий модуль), а кнопки формы проверять Vanessa, данные — COM после прогона.

**`НайтиПоНомеру` у документа с периодической нумерацией** (`numberPeriodicity` Year, Quarter…) без второго
параметра (дата интервала) документ не нашёл. Искать запросом `ГДЕ Номер = &Н УПОРЯДОЧИТЬ ПО Дата УБЫВ` или
передавать дату. Номер строковый с нулями (`numberLength` 11) — `'%011d' % номер`. Уверенность MEDIUM: проверено
на одном документе УАТ.
