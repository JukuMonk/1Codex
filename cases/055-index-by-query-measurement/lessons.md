# Уроки

**Симптом.** Отборы в живых запросах шли по неиндексированным полям растущих таблиц: `уатМаршрутныйЛист.ДокументОснование` и `.ТС` (статус заявки, живые листы, место машины), `уатПунктыНазначения.мвмУзелКарты` (на каждой сборке пакета), второе измерение регистра `мвмПривязкаГрафаКГеозонам.Элемент`.

**Почему.** Сверка всех запросов проекта с `.mdo`: поля в `ГДЕ`/`ПО` против `<indexing>`. Основной индекс регистра по второму измерению не работает. Узлы, проезды, кэш маршрутов (поиск по всем измерениям) и регистры чата (отбор по первому измерению) индексов не требуют.

**Что изменилось.** Тег `<indexing>Index</indexing>` ставится генератором: после `fillValue`, перед `fullTextSearch` — место по типовым объектам (`ItobГеографическийКлассификатор`). Индекс на типовом реквизите — реструктуризация таблицы при обновлении базы.

**Коммиты.** MVM 4e0b2fc.
