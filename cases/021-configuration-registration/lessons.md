# Уроки

**Что.** Каждый объект верхнего уровня прописан в Configuration.mdo строкой
своей группы: `<dataProcessors>DataProcessor.Имя</dataProcessors>`. Без неё
объект не существует для конфигурации.

**Правило.** Регистрация — часть создания объекта, вместе с записью в
подсистему и, при необходимости, в роль. Место — последним в группе
(`edt_lib.register_in_configuration`); общие картинки — по алфавиту.
Дочерние подсистемы в корень не пишутся.

**Коммиты.** EDT 145882b2; MVM 9027ea5 (генератор).

**Ссылки.** `tools/check_project.py` («не прописан в Configuration.mdo»).
