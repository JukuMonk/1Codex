# Уроки

**Панель множественного выделения 8.5 — HIGH (проверено прогоном, снимок `after/панель_выделения_с_командами.png`).**
При выделении нескольких строк таблица 8.5 показывает вместо своей командной панели системную панель множественного
выделения. Команда формы попадает на неё, только если у команды «Использование выделенных строк» = Использует
**и** задана «Используемая таблица» (`ИспользуемаяТаблица` / `AssociatedTable`); без таблицы команда «не будет показана
в меню ни одной таблицы формы» (Руководство разработчика 8.5.1, 7.7.6.8.2). `SelectedRowsUse=Use` в XML — мало.
Тег XML для таблицы в выгрузке не нашли — задаём кодом в `ПриСозданииНаСервере` (`after/команды_выделенных_строк.bsl`),
CheckModules проверяет имена. Строки для обработки — `Элементы.Т.ПолучитьСтрокиДляОбработки()` (выделенные или
текущая). Временные кнопки той же команды в панели формы платформа после этого сама скрывает.

**Подбор «флажками» в 8.5 — родное выделение строк**, не своя колонка «Пометка» (будет второй переключатель в строке):
флажки таблицы, флажок в заголовке — «все»; программно — `Элементы.Т.ВыделенныеСтроки.Добавить(Ид)`.

**Тест-клиент 8.5.1 (уровень 9) — MEDIUM (по прогонам, `reference/testing-ui/ТестUIМенеджер.Module.bsl`):**
- кнопка выбора поля — `ТестируемоеПолеФормы.Выбрать()` (`StartChoosing`; `НажатьКнопкуВыбора` нет): работает у
  ссылочного поля шапки и у ссылочной ячейки таблицы в режиме правки (шаг `изменить` перед `выбор`); у строковой
  колонки с кнопкой выбора и своей формой по `StartChoice` — «Неподходящий тип элемента управления», дальше прогон висит;
- `ВыделитьВсеСтроки()` у таблицы работает (снимок панели выделения);
- стандартную «Записать» формы объекта не нажимать (висит) — записать объект через COM до прогона;
- рискованные шаги — необязательными (`?шаг`), окно после них закрывать `закрыть-форму | начало заголовка` (не закроет
  родительскую форму, если выбор не открылся); `закрыть | без сохранения` — ответ «Нет», если 1С спросит;
- ~20 с на шаг по формам с реальными данными: сценарий — частями по 15–20 шагов, иначе «журнала нет» за 900 с.

**Документация платформы — на ИТС по входу.** web_fetch отдаёт только оглавление; открыть страницу во встроенном
браузере и попросить пользователя войти (пароль не вводить), затем читать текст страницы (`javascript_tool`, поиск по
номеру раздела). Имена свойств встроенного языка и их английские пары — строками UTF-16 в dll платформы
(`mngcore.dll`, `mngdsgn.dll`: «ИспользуемаяТаблица … AssociatedTable»).
