# Уроки

**Симптом.** 11 179 вызовов `ЗначенияРеквизитовОбъекта` за один «Распределить» (серверный профиль); «Обновить» экрана шло 1,2 с + 1,7 с двумя серверными вызовами.

**Почему.** Свойства упаковки читались через `Строка.ВидУпаковки.Нагрузка` по два раза на каждую строку груза; место машины — на каждую пару «машина × заявка»; параметры ТС — на каждый расчёт маршрута; `ПолучитьОбъект()` использовался как проверка существования ссылки.

**Что изменилось.** Всё, что нужно строкам выборки, — полем того же запроса (`ЕСТЬNULL(ВЫРАЗИТЬ(… КАК Справочник.X).Поле, 0)`); всё, что не меняется за вызов, — в кэш (соответствие в функции или модуль повторного использования); один серверный вызов на одно обновление экрана; существование — `ОбщегоНазначения.СсылкаСуществует`. Искать такие места скриптом: функции с запросами, вызванные внутри `Цикл`.
