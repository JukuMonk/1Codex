# Уроки

**Симптом.** «Переменная не определена (ПериодРейсов)» при первом открытии формы; компилятор молчит.

**Почему.** В процедуре `БезКонтекста` формы нет: реквизиты недоступны, обращение к ним — обращение к несуществующей переменной.

**Что изменилось.** Всё нужное передаётся параметрами. Генератор формы проверяет: реквизит, упомянутый в процедуре без контекста, обязан быть её параметром или локальной переменной (`проверить_контекст_реквизитов`).

**Коммиты.** MVM c1a4422.

**Ссылки.** `knowledge/bsl.md` §1; cases 010, 011.
