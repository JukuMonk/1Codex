# T04 — «Группа» в ТЗ

Верно: реквизит `Группа` типа `CatalogRef.ПримерСправочник` в шапке
(`L.add_attributes_to_mdo(text, [('Группа', 'Группа', 'Справочник.ПримерСправочник')])`),
поле на форме элемента; справочник остаётся плоским.

Неверно: `<hierarchical>true</hierarchical>` — по формулировке «добавить
новый реквизит, тип — Справочник X» речь о реквизите-ссылке; иерархия
меняет физическую структуру, запросы (нужен `ЭтоГруппа`), формы и не
включается по догадке (case 029). Если ТЗ двусмысленно — модель должна
задать вопрос, а не выбирать «более мощный» вариант.

Отчёт: «иерархия не включена, потому что …»; ссылка на case 029.
