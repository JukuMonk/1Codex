# УАТ: маршрутный лист, записанный в режиме обмена, не открывается — вопрос «Требуется конвертация… Релиз 1.1.21»

**Проект и платформа.** МВМ — «Заводская логистика» АО «Метровагонмаш» на типовой 1С:ТЛЭиУА КОРП (УАТ) 1.1.36.1,
проект EDT, платформа 8.3.27.2342 (копии для тестов) и 8.5.1.1529 (ПСИ через Apache); ДиЗ-06 к ТЗ-08, 09.10.2026.

**Задача.** Свой код создаёт маршрутный лист (`Документ.уатМаршрутныйЛист`) для грузоподъёмного механизма: одна
точка, вид операции «Произвольный», время работы — своё. Типовой `ПередЗаписью` пересчитывает «план выполнения» по
строкам (у листа из одной точки он становится равен началу), поэтому лист пишется с
`ОбменДанными.Загрузка = Истина`. Проверка — Vanessa со снимками форм для отчёта заказчику.

**Что пошло не так.**
1. Через COM всё верно (лист, основание, брони, статусы заказа), а снимок формы листа в тест-клиенте — пустой:
   видны только «Основное / Присоединенные файлы / События по перевозке», тела формы нет. Пауза 15 с не помогает;
   шаг «я активизирую поле с именем "ДокументОснование"» падает «Элемента формы … не найдено», в журнале
   регистрации у ошибки шага — `ИмяАктивнойФормы: ErrorWindow`. Лист обычного рейса (записан без режима обмена)
   тем же сценарием открывается полностью.
2. На видео окна ошибки нет: запись и снимок берут одно большое окно клиента, а окно вопроса — отдельное окно
   процесса 1cv8c размером 667×266 с заголовком «1С:Предприятие». Снимок всего экрана тоже не помог — клиент
   копии был позади, в кадр попал рабочий стол пользователя.
3. Снимок КАЖДОГО окна процесса тест-клиента шагом сценария показал текст: «Требуется конвертация данных
   документа в формат "Релиз 1.1.21". При конвертации будет выполнен расчет итогов…». Форма листа в
   `ПриОткрытии` вызывает `ВопросКонвертация_2_2_21()`, если `Объект.Статус` пуст. `Статус` ставит
   `Документы.уатМаршрутныйЛист.РассчитатьСтатусДокумента(ЭтотОбъект)` в типовом `ПередЗаписью` — а в режиме
   обмена `ПередЗаписью` выходит сразу.
4. После исправления статуса в полном прогоне форма снова пустая, а в пробе на той же базе открывается. Снимок окон
   показал другую ошибку: «Значение не является значением объектного типа (ЗначениеКопирования)». Навигационную
   ссылку сценарий брал запросом «первая бронь операции» — попалась старая отменённая бронь с ПУСТОЙ ссылкой на
   лист; `e1cib/data/…?ref=000…` открывает форму нового объекта с параметром копирования, и типовая падает.

**Итог.** Перед записью в режиме обмена — `РассчитатьСтатусДокумента(Объект)` (при создании и при каждой
перезаписи своим кодом); уже записанным листам статус дозаполнить. Ссылку для сценария брать по непустой и не
помеченной ссылке.
