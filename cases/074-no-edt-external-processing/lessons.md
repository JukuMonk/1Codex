# Уроки

**Выбор места.** Новый инструмент над данными расширения — внешняя обработка: конфигурация и расширение не меняются, сборка 3 с, переоткрытие в том же сеансе. Типы расширения в метаданных `.epf` при сборке неизвестны → реквизиты `ЛюбаяСсылка` (`cfg:AnyRef`), объекты расширения — только в коде. Расширение из XML не грузить: его выгрузка 8.3.27 не загружается обратно даже без правок.

**Формат.** Модуль объекта внешней обработки — `<Имя>/Ext/ObjectModule.bsl` (внутри папки объекта, рядом с `Forms`). Не там — сборка молча проходит, а методов нет. Сборка модули не компилирует: ошибка видна при `ВнешниеОбработки.Создать` через COM со строкой и колонкой — это и есть цикл «правка → сборка → COM».

**Имена в BSL.** Запрещены не только ключевые слова языка запросов (case 016, 065), но и языка: `И`, `ИЛИ`, `НЕ` как имена переменных — «Неопознанный оператор». В модуле формы заняты и свойства формы: `Окно`, `Параметры`, `Объект`, `Элементы`, `ЭтаФорма` (case 010) — «Поле объекта недоступно для записи (Окно)». Метод у выражения `Новый Тип(...)` не вызывается — сначала переменная.

**Проверка.** Ядро — в модуле объекта с `#Если Сервер Или … ВнешнееСоединение`; Python через COM вызывает методы и сравнивает с независимой реализацией того же алгоритма. Через COM очищать реквизит `pythoncom.Empty` (не `None`); ссылки сравнивать по `УникальныйИдентификатор()`.

**Настоящие нажатия без правки конфигурации.** Интерпретатор сценария (`platform.py ui`) вынесен в отдельную внешнюю обработку-менеджер (`reference/testing-ui/ТестUIМенеджер.Module.bsl`): тестируемый клиент `/TESTCLIENT -TPort N /Execute <проверяемая.epf>`, менеджер `/TESTMANAGER /Execute <менеджер.epf> /C "сценарий;журнал;N"`. В копии базы до прогона: снять предупреждение об опасных действиях у пользователя и ответить БСП «это копия» (`ЗапретитьРаботуСВнешнимиРесурсами`), иначе диалог «база перемещена» перехватывает фокус. Окно формы закрывать через `ТП.ПолучитьАктивноеОкно().Закрыть()`.
