# «Наименование не заполнено» при записи, хотя оно собирается при записи; сравнение ссылок через COM

**Проект и платформа.** «ФРЕГАТ: управление проектами» (UP), своя конфигурация без EDT, 8.5.1.1529; ДиЗ-05 к ТЗ-01,
18.10.2026.

**Замечание заказчика.** Справочник «Версии структуры объектов»: «По кнопке «Записать» название автоматически не
формируется, хотя реквизиты заполнены» — на снимке «Поле «Наименование» не заполнено». Наименование по шаблону
собиралось в `ПередЗаписью` (ДиЗ-03), COM-тест той доработки проходил: он писал объект программно.

**Сделано.** `after/ObjectModule.bsl`: наименование и пустой номер — в `ОбработкаПроверкиЗаполнения` и в `ПередЗаписью`;
в форме — сразу при изменении полей шаблона. Там же — маппинг (новые ТЧ, вкладка), тип сценария, справочник адресов
(`after/диз05.py`), проверки — `after/тест_диз05.py`.
