# Поле HTML и мост со страницей — ПримерКарта

**Что демонстрирует.** Обработка с формой из одного поля HTML на всю форму
(`HtmlFieldExtInfo`: `width 70` + `height 10` ВМЕСТЕ с растяжением — без
них документ нулевой высоты, case 022; обработчик `DocumentComplete`),
текстовый макет `СтраницаHTML` со страницей (CRLF, короткие строки —
case 023) и мост «1С ↔ страница» без вызова JS из 1С:

- 1С → страница: модуль пишет JSON в скрытые DOM-поля `in_package` и
  подпись в `in_package_sig`; страница опрашивает подпись таймером и
  разбирает пакет;
- страница → 1С: команды складываются в `bridge_out`, модуль читает их
  обработчиком ожидания (`ОпросМоста`, 40 мс через `setInterval` на стороне
  страницы — `requestAnimationFrame` в поле 1С не гарантирован) и
  подтверждает в `out_ack`;
- `appReady` — первая команда страницы, после неё модуль шлёт данные.

Модуль показывает: чтение макета `ПолучитьМакет(...).ПолучитьТекст()` и
склейку строк, разрезанных `Символ(1)`; `ОтправитьВСтраницу`; `ОпросМоста`
(отключается на время серверной записи — иначе очередь копится и клиента
«выбрасывает»); `ВJSON`/`ИзJSON` через `ЗаписьJSON`/`ЧтениеJSON`. HIGH —
сокращённая копия боевого моста АРМ диспетчера (полный текст —
`reference/DataProcessors/мвмАРМДиспетчера/Forms/Форма/Module.bridge-extract.bsl`).

**Обязательные файлы.**

```
ПримерКарта/ПримерКарта.mdo                              ← <forms>, <templates>СтраницаHTML</templates>, <defaultForm>
ПримерКарта/Forms/Форма/Form.form
ПримерКарта/Forms/Форма/Module.bsl
ПримерКарта/Templates/СтраницаHTML/Template.txt          ← текстовый макет: CRLF, ≤ 900 симв./строка
```

**Что можно менять.** Содержимое страницы (JS/CSS внутри — среда V8WebKit
уровня Safari 13: ES2018, без `?.`/`??`, без флекс-`gap`), состав пакета,
набор команд моста. Не менять: имена DOM-полей и порядок подписи (обе
стороны сходятся на них), `width/height` поля, порядок «страница
разобрана → appReady → данные».

**Что согласовано.** `<templates>` в .mdo ↔ папка `Templates/СтраницаHTML`;
имя реквизита `HTMLСтраницы` ↔ путь данных поля; имена `in_package`,
`in_package_sig`, `bridge_out`, `out_ack` — в модуле и в странице.

`reference/DataProcessors/мвмАРМДиспетчера` (две формы на одном модуле:
основная и «Выбор пункта на карте»).
