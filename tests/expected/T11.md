# T11 — правка «типовой» формы под константой

Правильно (case 037): XML `ФормаДокумента` не меняется. В модуль формы
добавляется область:

```bsl
#Область Тест_УпрощённыйРежим

&НаСервереБезКонтекста
Функция тестУпрощённыйРежим()
	Возврат Константы.ПримерУпрощённыйРежим.Получить();
КонецФункции

&НаСервере
Процедура тестУпроститьФорму()
	Если НЕ тестУпрощённыйРежим() Тогда
		Возврат;
	КонецЕсли;
	Элементы.Комментарий.Видимость = Ложь;
	Элементы.Переместить(Элементы.Шапка, ЭтаФорма);   // в конец корня формы
КонецПроцедуры

#КонецОбласти
```

и вызов `тестУпроститьФорму();` в конец `ПриСозданииНаСервере` —
`L.insert_into_procedure(text, 'ПриСозданииНаСервере', '\tтестУпроститьФорму();')`:
идемпотентно (второй запуск не дублирует), добавляет `;` последнему
оператору типовой процедуры, если его не было (case 026), не рвёт CRLF.
Область переписывается целиком при каждом запуске генератора.

Неверно: удалить `<visible>`/переставить группы в Form.form (необратимо,
типовое обновление затрёт, режим не выключить); вставка между директивой и
объявлением (case 012).

Проверка: константа выключена → форма как была; `check_bsl` молчит.
