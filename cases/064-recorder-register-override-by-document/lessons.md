# Уроки

**Симптом.** Корректировочный график работ не проводится: «Запись с такими ключевыми полями существует! : eamГрафикиРаботыСотрудников: <сотрудник>, <дата>, 1 (Номер строки: 2)». Основной график проводится.

**Почему.** Регистр сведений, подчинённый регистратору, всё равно требует уникальности (период +) измерений во ВСЁМ регистре, а не внутри набора документа. Замысел «действует запись более позднего документа» (читатель: `МАКСИМУМ(ДатаДокумента)`) невозможен, если признак документа — реквизит: основной и корректировочный пишут одинаковые измерения.

**Что изменилось.** `ДатаДокумента` переведена из реквизитов в измерения (генератор метаданных), запрос-читатель не менялся. Реструктуризация при обновлении базы переносит данные сама.

**Правило.** Если несколько документов пишут «одно и то же» в регистр и действует последний — отличающий документ признак (дата/ссылка документа) должен быть ИЗМЕРЕНИЕМ. Проверять сценарий «второй документ на тот же ключ» прогоном, а не чтением: генератор демо-данных нашёл дефект, который пропустили ручные проверки.
