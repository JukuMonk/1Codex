# Запрет локальных минусов при изменении старых документов

Проект: собственная учебная конфигурация склада. Платформа 8.3.27.2325,
совместимость 8.3.27, XML 2.20, без EDT. Уверенность HIGH в проверенной области.

Исходная история: приход20, расход20, приход10. Новый расход1 между первым
приходом и расходом должен отклоняться: текущие9 скрывают исторический минус1.
Контролировать также уменьшение/отмену прихода, смену товара/склада/даты,
обычную запись проведённого документа, прямую запись движений и два сеанса.
