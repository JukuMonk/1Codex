# Перечисление — ПримерПеречисление

**Что демонстрирует.** Минимальный `Enum.mdo`: три значения с синонимами,
`useStandardCommands`, `quickChoice`, `choiceMode`. Уровень: HIGH (структура
снята с рабочих перечислений `reference/Enums/`).

**Обязательные файлы.** `ПримерПеречисление/ПримерПеречисление.mdo`.
Регистрация: `<enums>Enum.ПримерПеречисление</enums>` в Configuration.mdo.

**Что можно менять.** Имя, синоним, состав `enumValues` (у каждого свой
uuid и `<name>`; имя значения — то, что пишется в коде
`Перечисления.X.ИмяЗначения`, case 045). Порядок значений — порядок в
списке выбора.

**Что согласовано.** uuid объекта и значений — `stable_uid('Enum/…')`;
ссылки на перечисление в других примерах — `EnumRef.ПримерПеречисление`
(реквизит `Тип` справочника, отбор в отчёте:
`Перечисление.ПримерПеречисление.ПустаяСсылка`).

**Похожее.** `knowledge/metadata.md` §7; case 045 (имена значений сверять с
.mdo); `reference/Enums/мвмРежимДоступаГеозоны`, `мвмЦветНаКарте` (боевые).
