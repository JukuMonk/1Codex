# Уроки

**Симптом.** Белый экран при живой странице и работающих скриптах.

**Почему.** Задали только autoMaxWidth/autoMaxHeight и растяжение — у
документа viewport нулевой высоты, а вся вёрстка на `html,body{height:100%}`.

**Правило.** У поля HTML `width 70` и `height 10` ВМЕСТЕ с растяжением (числа
как у типовых АРМ). Осмотр документа на `ДокументСформирован` отложить:
страница ещё разбирается («готовность:loading, элементов:24»).

**Коммиты.** EDT 3ee78634.

**Ссылки.** `tools/edt_lib.html_field`, `examples/forms/html-field-form/`.
