# Уроки

**Документ без EDT — HIGH.** `document_xml` по спецификации (реквизиты шапки, несколько табличных частей, ссылка на
другой свой документ в колонке ТЧ) грузится полной загрузкой и сверяется 0 расхождений. Своя форма документа:
основной реквизит `cfg:DocumentObject.X`, стандартные — `Объект.Number`, `Объект.Date`, колонка «N» —
`LineNumber`; свойства формы как пишет Конфигуратор: `AutoTime=CurrentOrLast`, `UsePostingMode=Auto`,
`RepostOnWrite=true`; в спецификации — `формы={'ФормаДокумента': …}` + `формы_по_умолчанию={'Object': 'ФормаДокумента'}`.
Модуль формы документа не обязателен (форма без событий грузится без `Module.bsl`). Модуль менеджера —
файл `Documents/X/Ext/ManagerModule.bsl` без упоминания в XML; представление ссылки («МЛ-26-17294 · ДСЕ» вместо
«Маршрутный лист производства 000… от …») — `ОбработкаПолученияПолейПредставления` + `ОбработкаПолученияПредставления`
(`after/ManagerModule_МаршрутныйЛист.bsl`). Образец — `after/формы_и_документы.py`.

**Раскладка «шапка выше, табличная часть сразу под ней»:** группа `horizontal` из двух-трёх групп `vertical`
(колонки шапки) + `pages` со страницами «Операции» (таблица) и «Комментарий» (многострочное поле без заголовка).

**Нативная форма «красиво» без поля HTML.** Разметка — построителем (таблицы значений с колонками, страницы с числом в
заголовке, надписи-показатели «заголовок / значение / пояснение» в группах `NormalSeparation`), оформление — кодом в
`ПриСозданииНаСервере` (построитель стили не задаёт, а XML оформления вручную дольше и хрупче):
- `Элементы.Значение.Шрифт = Новый Шрифт(, 15, Истина)`, `Элементы.X.ЦветТекста`, `Элементы.Группа.ЦветФона`;
- `УсловноеОформление.Элементы.Добавить()` + `ЭлементОтбораКомпоновкиДанных` по колонке-коду (`Станки.КодСостояния = "W"`)
  → `ЦветТекста`/`Шрифт` для поля `<Таблица><Колонка>`; поле — вся таблица (`"ОперацииЛистов"`) красит строку;
- ограниченный выбор в колонке (только допустимые станки строки) — событие `StartChoice` у колонки,
  `СтандартнаяОбработка = Ложь`, `ПоказатьВыборИзСписка(Новый ОписаниеОповещения(…, ЭтотОбъект, ИдентификаторСтроки), …)`;
- данные — тем же JSON, что раньше получала страница (`ЧтениеJSON` → `ПрочитатьJSON(…, Истина)` в серверной процедуре
  формы): бизнес-логика модуля не меняется при переходе HTML → нативная форма.
Образец — `after/Module_ЗаданияМастера.bsl` (процедуры `Оформить`, `ОформитьПоле`, `ЗаполнитьДанные`).

**Клиентский код — проверять в веб-клиенте, ошибки искать в журнале регистрации.** В веб-клиенте на клиенте нет
`XMLСтрока` (как и `ЗаписьJSON`, case 073): процедура `&НаКлиенте` падает только при нажатии, тонкий клиент, снимки и
COM этого не видят. Дата строкой на клиенте — `Формат(Дата, "ДФ=yyyy-MM-dd") + "T00:00:00"` (буквы внутри `ДФ=`
небезопасны — строку собирать сложением), сериализация — на сервере. Найти, что видел пользователь:
`ВыгрузитьЖурналРегистрации(Таблица, Новый Структура("Уровень, ДатаНачала", УровеньЖурналаРегистрации.Ошибка, …))`
через COM — комментарий содержит модуль и строку (`{DataProcessor.X.Form.Форма.Form(257,79)}`), «Представление
приложения» — «Веб-клиент» (`after/журнал_ошибок.py`).

**Имена глобальных методов — не для своих функций:** `ИмяПользователя()` в общем модуле → `/CheckModules`
«Функция <<?>>ИмяПользователя()». Натуральный логарифм — `Log(x)` (`Ln` нет), экспонента — `Exp`, десятичный — `Log10`.

**.dt для показа на чужом сервере.** `/DumpIB` пакетным Конфигуратором; базу не держат клиенты, COM и процесс
веб-публикации (остановить службу/процесс Apache на время выгрузки). Проверка обязательна: `CREATEINFOBASE` СТРОКОЙ
(`'"1cv8.exe" CREATEINFOBASE File="…"'`, shell) + `/RestoreIB` БЕЗ `/N` (в пустой базе пользователей нет) + COM:
ключевые данные и константы (`after/dt_выгрузка.py`). Если стенд показывает «сейчас», а датчиков на чужом сервере нет:
- данные закладывать вперёд на весь период показа (у ZHDRM — имитатор с «сейчас» + N часов);
- ВСЁ, что база досчитывает до текущего момента (регистры состояний, итоги, расчёт по расписанию), досчитать до конца
  заложенного периода явно (`ОбновитьСостояние(Объект, МоментUTC)`), иначе состояние «сейчас» пропадёт через час;
- обмен по расписанию выключить, а «сейчас» в формах брать из интервалов на текущий момент (флаг-константа режима
  показа), не из «последней записи».

**Инструменты Git Bash.** Файлы выгрузки — UTF-8 с BOM и CRLF: `sed -i` молча переводит их в LF (весь файл в diff);
правка готовых файлов — Python-скриптом С ФАЙЛА (`newline=''`, счёт вхождений, тот же перевод строк). Скрипт правки,
содержащий `'''` или неэкранированные кавычки, в heredoc команды может сорвать разбор («unexpected EOF») — писать его
файлом и запускать `python файл.py`.
