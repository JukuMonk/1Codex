# Регистр накопления — ПримерОстатки

**Что демонстрирует.** Регистр остатков (`registerType Balance`) с одним
измерением `Объект` и ресурсом `Количество`; движения по нему делает
`ПримерДокумент` (`registerRecords` в документе). **MEDIUM**: в
проекте-источнике своих регистров накопления не было, структура снята с
типового объекта и проверена только структурно (`check_mdo`, песочница),
в базу не загружалась.

**Обязательные файлы.** `ПримерОстатки/ПримерОстатки.mdo`; регистрация
`<accumulationRegisters>AccumulationRegister.ПримерОстатки</accumulationRegisters>`.

**Что можно менять.** Измерения, ресурсы, реквизиты (`edt_lib.accumulation_register_mdo`);
`registerType Turnovers` для оборотного регистра — проверять по типовому.

**Что согласовано.** uuid `stable_uid('AccumulationRegister/…')`; имя
регистра в `registerRecords` документа; таблица остатков в запросе
`examples/bsl/query-patterns.bsl` (`РегистрНакопления.ПримерОстатки.Остатки(&Сейчас, )`).

**Похожее.** `knowledge/metadata.md` §6; `metadata/document/`. Перед первым
использованием в бою — сверить с регистром типовой конфигурации того же типа
и прогнать проведение документа.
