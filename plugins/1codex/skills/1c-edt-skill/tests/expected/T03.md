# T03 — регистр сведений

Ключевой момент: имена `С` и `По` — ключевые слова языка запросов;
`Записи.По КАК По` → «Ожидается имя» в бою (case 016). `edt_lib.information_register_mdo`
на них падает. Ожидаемая замена: `СменаС`/`СменаПо` (любые не ключевые).

```python
L.information_register_mdo('ТестСмены', 'Смены (тест)',
    dimensions=[('Сотрудник', 'Сотрудник', 'Справочник.ПримерСправочник')],
    resources=[('СменаС', 'Смена с', 'ДатаВремя'), ('СменаПо', 'Смена по', 'ДатаВремя'),
               ('Примечание', 'Примечание', 'Строка(0)')],
    forms=[('ФормаЗаписи', 'Форма записи'), ('ФормаСписка', 'Форма списка')],
    default_forms=[('defaultRecordForm', 'ФормаЗаписи'), ('defaultListForm', 'ФормаСписка')])
```

Признаки: `<defaultRecordForm>`/`<defaultListForm>` стоят ПОСЛЕ `editType`
и ДО `dataLockControlMode` (case 039); измерение с `<master>true</master>`
если нужна подчинённость; `informationRegisterPeriodicity Nonperiodical`,
`writeMode Independent`; формы по `examples/forms/record-form` и
`metadata/information-register/…/ФормаСписка`; регистрация, подсистема,
роль (`Read`, `Update`, `View`, `Edit` по необходимости); `check_project` 0.

Отчёт: чтение регистра — запросом, не `Получить` (case 018), если задача
«есть ли запись».
