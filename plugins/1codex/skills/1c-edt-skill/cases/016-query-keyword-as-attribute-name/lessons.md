# Уроки

**Симптом.** `Записи.По КАК По` → «Ожидается имя»; пакет не собрался, АРМ
пустой (та же цена, что у case 015).

**Что изменилось.** Ресурсы переименованы в `НедоступнаС`/`НедоступнаПо` —
в спецификации генератора, в самом .mdo (регистр пересоздан: данных ещё не
было; с данными это реструктуризация с потерей), в запросах, в записи, в демо.
Проверка псевдонимов `КАК <ключевое>`. «Ссылка», «Дата», «Номер»,
«Значение» — законные имена полей, их в список не включать.

**Правило.** Имена `По, В, Из, Где, Для, Все, Как, Есть, Не, И, Или`
запрещены как имена реквизитов и псевдонимы (HIGH); остальные ключевые —
MEDIUM.

**Коммиты.** MVM 34258c8; EDT 5c013310.
