# Дельта-пакет вместо .cf: частичная загрузка изменённых объектов; корень — вместе с поставкой; разовая ошибка выгрузки EDT

**Проект и платформа.** МВМ — «Заводская логистика» на типовой 1С:ТЛЭиУА КОРП (УАТ) 1.1.36.1 на поддержке, проект
EDT; у нас 8.3.27.2342, у заказчика база ПСИ на сервере (8.3.27.2214); 07–09.10.2026.

**Задача.** Заказчик обновляет свою базу не всем `.cf` (568 МБ), а пакетом только изменённых объектов: эталон (что
стоит у заказчика) и «стало» разворачиваются во временные базы, выгружаются `DumpConfigToFiles`, сравниваются по
содержимому; изменённые и новые объекты верхнего уровня кладутся целиком в `files/`, загрузка —
`/LoadConfigFromFiles <files> -listFile <список>` + `/UpdateDBCfg` (скрипт `load.ps1`).

**Что пошло не так.**
1. Пакет с НОВЫМИ объектами (константа, регламентное задание) без `Configuration.xml` — «Ошибка добавления объекта …
   нельзя добавлять объекты метаданных без загрузки родительского объекта».
2. Добавили один `Configuration.xml` (корень изменился — в нём состав) — проверка пакета на копии эталона показала:
   частичная загрузка корня без `Ext/` СТИРАЕТ корневые `Ext` — модули приложения и сеанса, командный интерфейс,
   справку и `ParentConfigurations` (поставочную конфигурацию, т. е. поддержку). Без `ParentConfigurations/*.cf`
   снова «нельзя добавлять объекты метаданных без загрузки родительского объекта».
3. По ходу дважды (08–09.10) выгрузка проекта EDT в XML (для копии с полной конфигурацией) ответила «дефект в файлах
   проекта» — повтор прошёл. Один раз совпало с коммитом в репозиторий проекта EDT во время выгрузки. Скрипт копии
   при этом базу не перегрузил, и проверка тихо пошла на СТАРОЙ конфигурации.

**Итог.** Корень конфигурации — ОДИН объект: `Configuration.xml` + все корневые `Ext/**` (вместе с
`ParentConfigurations`, ~280 МБ у УАТ); переносится целиком, когда изменился корень или в пакете есть новые объекты.
Каждый пакет перед отправкой — накатить на копию эталона, выгрузить и сравнить со «стало»: отличаться может только
`ConfigDumpInfo.xml`. Выгрузку EDT не запускать во время коммитов в проект; упала — повторить и смотреть первые
строки вывода копии (перегружена ли база).
