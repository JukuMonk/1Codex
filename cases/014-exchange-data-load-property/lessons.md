# Уроки

**Симптом.** «Пункт «Цех № 69» не привязался к узлу: Поле объекта не
обнаружено (ОбменДаннымиЗагрузка)» — только в окне сообщений, пункты не
привязались.

**Почему.** Это свойство СТРУКТУРЫ `ОбменДанными`; слитное написание
компилятор пропускает, платформа не находит. Правильный образец стоял в том
же модуле строкой ниже.

**Правило.** Свои же места копировать, а не писать по памяти; список таких
написаний — в `tools/check_bsl.py` (TYPOS).
