# Отчёт — ПримерОтчет

**Что демонстрирует.** Отчёт на СКД без своей формы: `.mdo` с
`mainDataCompositionSchema`, `defaultForm`/`defaultSettingsForm`/
`defaultVariantForm` на типовые формы отчёта БСП (`ОтчетыКлиент` не нужен),
схема `Template.dcs` с одним набором-запросом, выбранными полями, итогом,
отбором по ссылке (`DesignTimeValue … ПустаяСсылка`) и по строке
(`xs:string`) — case 034, группировкой `Состояние` с вложенной группировкой
детальных записей — case 035, устойчивыми `userSettingID`. HIGH: та же
сборка, что девять боевых отчётов (`reference/Reports/`).

**Обязательные файлы.**

```
ПримерОтчет/ПримерОтчет.mdo
ПримерОтчет/Templates/ОсновнаяСхемаКомпоновкиДанных/Template.dcs   ← табы, CRLF
```

Регистрация: `<reports>Report.ПримерОтчет</reports>`; в подсистему —
`content` + команда `Report.ПримерОтчет.Command.Открыть`; в роль — `Use`, `View`.

**Что можно менять.** Запрос (в XML экранировать `& < >`; правила запросов
те же, что в BSL — cases 015–017, 031: компилятор его не видит вовсе), поля
и подписи, отборы, группировки, итог (`edt_lib.dcs_schema`). Имя схемы
`ОсновнаяСхемаКомпоновкиДанных` и ссылки в .mdo — оставить.

**Что согласовано.** uuid `stable_uid('Report/…')`; `userSettingID` —
uuid5 от имени отчёта и поля; `Перечисление.ПримерПеречисление.ПустаяСсылка`
в отборе; `Справочник.ПримерСправочник` в запросе.

**Похожее.** `knowledge/skd.md`; `reports/report-with-parameters-and-grouping`
(параметры периода, две группировки); `examples/skd/README.md`.
