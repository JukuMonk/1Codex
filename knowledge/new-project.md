# Новый проект без EDT

Основной режим — своя учебная конфигурация в Codex. Источник — XML Конфигуратора.

## Подготовка

Определить учебный сценарий, версию платформы, совместимость, префикс и путь
отдельной тестовой базы. Установки платформы не означают выбранную версию проекта.
Для конфигурации с нуля создать пустую базу выбранной платформой, выгрузить
её конфигурацию `/DumpConfigToFiles` и использовать этот корень как шаблон
(`InternalInfo`, версия формата и корневые `Ext/**`). См. кейсы 078 и 084.
Для существующей конфигурации работать с её копией и полной исходной выгрузкой.

## Подключение Codex

```powershell
python <skill>/tools/new_project.py <выгрузка> <инструменты> --prefix <пф> --name "Название"
```

Команда валидирует `Configuration.xml`, создаёт `AGENTS.md`, карту и образец
настроек платформы. При необходимости указать `--v8 <1cv8.exe>` и `--ib <тестовая-база>`.
Существующие инструкции/настройки не заменяет. Git, COM и базы не изменяет;
настройки Claude и резервное копирование в GitHub по умолчанию не создаёт.

## Первый объект

Использовать `designer_lib` и аналог целевой версии. Генератор проекта —
спецификация и вызовы библиотеки. UUID сохранять, типы и роли сверять с
метаданными. Объект включить в состав конфигурации, подсистему и нужные права.
Без БСП не переносить ссылки на её общие формы и модули.

Сначала линт, затем загрузка в тестовую базу, UpdateDBCfg, CheckModules,
обратная выгрузка и сверка, COM и UI: `knowledge/validation.md`.
Не запускать команды с путями и пользователями из чужих примеров.

## Совместимость со старым стартовым набором

Старый сценарий EDT доступен только явно: `--format edt --agent claude`.
Он не применяется в текущем проекте. `--hook` — только для явно выбранного
Claude Code; в Codex такой хук не устанавливается.


Для диагностики и исполнения использовать `tools/project_cli.py` и
`knowledge/project-runner.md`. JSON проекта хранить вне дерева XML-выгрузки,
work — в отдельном каталоге. Корень установленного навыка определяется по
активному SKILL.md; абсолютный путь версионного кэша в AGENTS.md не закрепляется.
