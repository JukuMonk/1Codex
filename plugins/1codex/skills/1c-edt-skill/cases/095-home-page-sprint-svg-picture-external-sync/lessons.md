# Уроки

**Сначала — как данные попадают в базу.** Перед записью из 1С в данные, которые приходят обменом, прочитать модуль
обмена: направление (UP — только Б24 → 1С), ключ сопоставления (код = ID внешней системы), какие поля перезаписываются
(дата закрытия задачи — да), есть ли уже «ручные» записи (21,7 тыс. записей времени с кодами вне диапазона ID). Вывод
UP: время писать можно — как форма элемента; закрывать задачу в 1С нельзя — обмен вернёт дату из Б24; «завершение
стадии» уже было устроено флажком записи времени, и форма спринта, и отчёты его считают. Новое поле не понадобилось.

**SVG-картинка вместо поля HTML.** `Новый Картинка(ПолучитьДвоичныеДанныеИзСтроки(СтрокаSVG))` → адрес во временном
хранилище → реквизит-строка поля картинки (`designer_lib.Form.picture`). 8.5.1 определяет формат SVG, кириллица
рисуется (проверено переводом в PNG через COM: `Картинка.Преобразовать(ФорматКартинки.PNG)`). Координаты — с точкой
(`Формат(Ч, "ЧРД=.; ЧГ=0")`), иначе «12,5» ломает картинку. Размер — кодом (`РазмерКартинки.Пропорционально`).

**Формат XML, который нашла загрузка.** Начальная страница `OneColumn` — элементы в `<Column>` («Текущее LeftColumn,
ожидаемое Column»; `designer_lib.home_page_xml`). Отображение команды — `TextPicture`, не `PictureAndText`
(исключение XDTO). Значения брать grep'ом по выгрузке, отдельно для команд и кнопок.

**Тест-клиент 8.5.1: флажок — `УстановитьОтметку()`** без параметров (с параметром — «Слишком много фактических
параметров»; `Нажать`, `ВвестиТекст`, `ПолучитьОтображаемыйТекст` — «Неподходящий тип элемента управления»). Шаг
`флажок` пробует способы по очереди и пишет в журнал сработавший.

**Итоговый кадр — PrintWindow можно.** Снимки по ходу — копией экрана (PrintWindow тормозит следующую загрузку списков:
602 с на «команде» после одного снимка); но после последнего шага тормозить нечему — `ui_итог.png` снимается
PrintWindow, если окно перекрыто или экран не рисуется. Для проверки вида формы — короткий сценарий, кончающийся на
нужном состоянии.

**Пересоздание песочницы возвращает защиту от опасных действий** (флажок пользователя хранится в базе): менеджер
`/Execute <epf>` висит на «Предупреждении безопасности», журнала нет. Программно не снимать — попросить пользователя
(Конфигуратор песочницы → Администрирование → Пользователи → «Основные»); песочницу без нужды не пересоздавать,
новую конфигурацию — просто загрузить.
