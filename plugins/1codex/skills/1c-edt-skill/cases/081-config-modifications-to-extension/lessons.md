# Уроки кейса 081

1. **«База» для сравнения — в самом `.cf`.** У конфигурации на поддержке выгрузка (`/DumpConfigToFiles`) содержит
   `Ext/ParentConfigurations/<Имя>.cf` — поставку, на которой сделаны доработки. Загрузить её (`/LoadCfg`) во
   вспомогательную базу и выгрузить: дальше `diff` двух выгрузок даёт ВСЕ доработки точно (`after/diff_cf.py` — по
   файлам и объектам, `diff_meta.py` — добавленные реквизиты/ТЧ/макеты и изменённые свойства, `bsl_methods.py` —
   модули по методам: новые, изменённые, вне методов).
2. **Генератор вместо ручного переноса** (`after/build_ext.py`, формат — выгрузка Конфигуратора 8.3.27):
   - новые объекты — копией файлов ПРОД (uuid сохраняются); новые реквизиты/ТЧ/макеты — в заимствованный объект
     элементами ПРОД; у заимствованной ТЧ — свои GeneratedType с новыми id и `ExtendedConfigurationObject`;
   - изменённый метод → `&ИзменениеИКонтроль("Имя")` + директивы + тело поставщика, разница — `#Вставка`/`#Удаление`
     по `difflib` (сравнение без концевых пробелов, в теле — строки поставщика); новые методы — как есть; модуль
     объекта/менеджера оборачивается тем же `#Если Сервер …`, что у поставщика;
   - изменённые свойства-коллекции (`RegisterRecords`, `Content` подсистемы и ФО) — в заимствованный объект только
     ДОБАВЛЕННЫЕ элементы; права роли — только объекты, которых нет у поставщика;
   - объекты основной конфигурации, на которые ССЫЛАЮТСЯ доработки (типы реквизитов, права, состав, формы) — пустые
     заимствованные: расширение не видит незаимствованное («Неизвестное имя типа»). У НПЦАП таких 23.
3. **Форматы заимствованного, которые платформа требует** (иначе «ошибка формата документа»):
   - общая форма — `<CommonForm>` без `<ChildObjects>`; PropertyState `Form` Extended, модуль — `Ext/Form/Module.bsl`;
   - план обмена — `<xr:ThisNode>` в InternalInfo (новый uuid);
   - подсистема — `<Content/>` (или только добавленное); командный интерфейс — ТОЛЬКО команды объектов расширения,
     иначе «Неизвестная команда …StandardCommand.Open» по каждой незаимствованной;
   - реквизит регистра из ресурса — без `TypeReductionMode`, `Balance`, `UseInTotals` и т.п.
4. **Форма — минимальная заимствованная**: `Form.xml` = `AutoCommandBar` (имя как у поставщика) + `<Attributes/>` +
   `<BaseForm version="2.20">` с тем же. Изменений состава нет, формой пользуется только модуль. Элементы, которые
   ПРОД добавлял в `Form.xml` (кнопка + команда), — кодом в `&После("ПриСозданииНаСервере")`: `Команды.Добавить`,
   `Элементы.Вставить(…, Тип("КнопкаФормы"), Родитель, Перед)`. Тип реквизита формы, расширенный в ПРОД, — проверить:
   у НПЦАП уже был `TypeSet cfg:CatalogRef`, правка не нужна. Генерированное расширение с такими формами грузится
   целиком (`/LoadConfigFromFiles -Extension`) — проблема кейса 074 касается ВЫГРУЗКИ реального расширения.
5. **В заимствованный регистр нельзя добавить измерение, ресурс И реквизит** в режиме совместимости ≤ 8.3.25
   (проверено на 8.3.21, 8.3.22, 8.3.25), а режим расширения не выше, чем у основной конфигурации. Поле регистра
   из доработки → свой РЕГИСТР-СПУТНИК: копия структуры типового (измерения + нужные ресурсы), запись — `&После`
   метода движений (той же таблицей/выборкой: строки 1:1, связь по `Регистратор + НомерСтроки`), чтение — левым
   соединением в запросах (правки перехватчика: строка поставщика → `#Удаление`, новые → `#Вставка`). Измерение-ключ
   (цена по серии) — спутник-копия всего регистра с этим измерением; в типовой пишутся строки без него.
6. **Контроль `&ИзменениеИКонтроль` проверять без платформы**: из перехватчика убрать `#Удаление`-блоки и маркеры =
   метод ПРОД; убрать `#Вставка` = метод поставщика (`after/verify_ext.py`). Платформа проверяет второе при
   подключении к сеансу — расширение просто не подключится.
7. **БСП и расширение, меняющее роли.** Права ролей конфигурации (`РегистрСведений.ПраваРолей`) БСП обновляет
   только в сеансе без таких расширений: первое обновление ИБ через COM — выключить расширение, обновить, включить
   (`after/ext_activate.py`). `Записать()` расширения через COM без запроса — `ЗащитаОтОпасныхДействий =
   ОписаниеЗащитыОтОпасныхДействий` с `ПредупреждатьОбОпасныхДействиях = Ложь`; там же снять `БезопасныйРежим`
   (внешние компоненты, файлы, HTTP интеграций).
8. **`CheckModules` не видит текстов запросов и схем.** Ссылки на объекты, которых нет в поставке, — сканером по
   коду и `Template.xml` (`after/check_refs.py`), поля и виртуальные таблицы — только выполнением: отчёты и печатные
   формы через COM (кейс 083).
