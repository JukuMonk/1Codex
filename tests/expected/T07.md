# T07 — сломанный модуль

`python tools/check_bsl.py tests/expected/fixtures/broken-module/Module.bsl` выдаёт:

```
строка 30: «Процедура ОткрытьЭлемент» без директивы компиляции — станет серверной (case 011)
строка 37: клиентский ОткрытьФорму() в серверной процедуре (case 011)
«ОбменДаннымиЗагрузка» — такого поля нет, нужно «ОбменДанными.Загрузка» (case 014)
строка 53: «ПустаяСсылка» без скобок — это метод (case 032)
строка 36: переменная «Параметры» — свойство формы, только для чтения (case 010)
строка 18: псевдоним «По» — ключевое слово запроса, «Ожидается имя» (case 016)
строка 23: одиночная кавычка в тексте запроса (case 015)
```

Чем кончится в бою (модель должна назвать):

1. `Процедура ОткрытьЭлемент` без директивы → серверная; `ОткрытьФорму` →
   «Процедура или функция с указанным именем не определена (ОткрытьФорму)»
   при нажатии кнопки. Исправление: `&НаКлиенте`.
2. `Параметры = Новый Структура` → «Поле объекта недоступно для записи
   (Параметры)». Исправление: `ПараметрыФормы`.
3. `КАК По` → «Ожидается имя», запрос не выполняется — форма открывается пустой.
   Исправление: `КАК Комментарий`.
4. `<> ""` внутри литерала → «Строка, не закрывающаяся кавычкой» при
   выполнении. Исправление: убрать условие, отсеять `ПустаяСтрока` в коде
   (или `<> """"`).
5. `ПустаяСсылка` без скобок → «Поле объекта не обнаружено (ПустаяСсылка)».
6. `ОбменДаннымиЗагрузка` → «Поле объекта не обнаружено (ОбменДаннымиЗагрузка)».
   Исправление: `ОбменДанными.Загрузка`.

Бонус (не обязателен): `ОбъектЭлемента.Записать()` в цикле без транзакции и
без проверки `Неопределено` от `ПолучитьОбъект()`.
