# Уроки

**Симптомы.** Инкрементальная загрузка: «Ошибка добавления объекта
Subsystem uuid=… : нельзя добавлять объекты метаданных без загрузки
родительского объекта» — на каждой дочерней по очереди. Полный импорт:
«Файл объекта не существует …/Subsystems/мвмПланЗавода.xml».

**Три захода (attempt-*).** (0) раздел без групп — прошёл; (1) группы у
прежнего имени — упал; (2) переименование — упал на другой дочерней. Каждый
объяснялся «порядком загрузки» и «переименованием родителя». Все три
ошибочны в диагнозе: дело было в файле дочерней.

**Причина.** Папка `Subsystems/Родитель/Subsystems/Дочерняя/` — только
место хранения. Связь «кто чей» держит строка в .mdo дочерней
`<parentSubsystem>Subsystem.Родитель</parentSubsystem>` (у двухуровневых —
`Subsystem.А.Subsystem.Б`). Без неё EDT не считает подсистему дочерней: в
родителе `<subsystems>` есть, а объекта в модели нет. Проверено по типовым:
Лицензирование → `Subsystem.Администрирование`.

**Что осталось верным из заходов.** uuid раздела при переименовании не менять
(новый uuid = новый объект); новые подсистемы база принимает полным
обновлением (case 020).

**Коммиты.** MVM 48bf876, c464d4f, 3ceef2e, 02b0363; EDT 8f12a603, 3712cff0,
daa2b106, be8fa82a, 0d80d502.
