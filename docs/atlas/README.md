# Исходники инженерного атласа

Результат сборки — **один автономный файл** `docs/index.html`. Его можно
переслать, открыть с диска или разместить на GitHub Pages. Внешние библиотеки,
шрифты и сетевые запросы для просмотра не требуются. Ссылки на репозиторий
открываются только по действию читателя.

Содержание соответствует библиотеке 1.1.0, тегу `v1.1.0`. Ссылки на правила
закреплены на этом теге. При обновлении атласа пересмотреть текст, версию,
исходный commit и дату, а не только счётчики. Тесты страницы не являются
повторной приёмкой инструментов на платформе 1С.

Состав:

- `content.py` — 12 схем: узлы, связи, пояснения, результаты и пути источников.
- `layout.cjs` — расчёт координат через закреплённый Dagre 3.1.3.
- `vendor/` — библиотека расчёта и её лицензии MIT; только для сборки.
- `build.py` — SVG, счётчики каталога, единый HTML и манифест.
- `template.html`, `style.css`, `app.js` — представление и интерактивность.
- `theme.css` — цвета и типографика атласа, тёмная тема по умолчанию.
- `stock-example.html` — учебный пример локального отрицательного остатка.
- `graph-layout.json` — координаты для проверки связности и пересечений узлов.
- `check.py` — проверки содержания, источников и графов.
- `check_browser.cjs` — проверки в Edge/Chromium, снимки и пробная печать.

Из корня репозитория, Python 3 и Node.js 20+:

```text
python docs/atlas/build.py --node <путь-к-node>
python docs/atlas/check.py
python tools/check_links.py
python tools/cases_sync.py проверить
```

Браузерные проверки требуют Playwright, установленного вне репозитория.
Передать его каталог через `NODE_PATH`, если пакет недоступен обычному Node.
Запуск создаёт собственный headless-браузер и блокирует все HTTP-запросы.

```text
node docs/atlas/check_browser.cjs docs/index.html <каталог-результатов> <путь-к-Edge>
```

Проверяются отсутствие внешних зависимостей, отображение всех узлов,
помещение подписей в рамки, клавиатура, поиск, масштабирование, уникальность
SVG-ID при разворачивании, пример остатков, темы, старые якоря и мобильная
ширина. Визуально проверить снимки после изменения оформления. Для полного
повторного запуска используйте новый каталог результатов или учитывайте,
что одноимённые файлы проверки перезаписываются.

Изменение `docs/index.html` не запускает публикацию. Публикация и выпуск
пакета плагина выполняются отдельно по поручению владельца.
