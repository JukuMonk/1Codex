# Работа с набором в Codex

Читать `SKILL.md` и `knowledge/codex.md`. Основной режим — XML Конфигуратора
без EDT. Исторические материалы EDT/Claude сохранены как справка.
Их пути, настройки, хуки и команды публикации автоматически не применять.

Изменения библиотек сохраняют совместимость. Документация: `tools/check_links.py`
и `tools/cases_sync.py проверить`; Python: синтаксис и поведение на временных
данных. Примеры менять генератором, затем пересобирать песочницу.
Проектные образцы не запускать на чужих базах, указанных внутри файлов.
