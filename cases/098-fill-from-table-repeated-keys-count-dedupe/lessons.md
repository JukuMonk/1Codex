# Уроки

**«Уже есть» ≠ «уже добавлено».** Защита от повторного заполнения по факту наличия ключа (`Найти`, `НайтиСтроки`,
`Соответствие[Ключ] <> Неопределено`) ломается, как только ключ повторяется в самом источнике: вторая строка
отбрасывается тем же заполнением, которое добавило первую. Правильная защита — по количеству: сколько раз ключ был
в приёмнике ДО заполнения, столько его строк источника и пропустить.

```bsl
Было = Новый Соответствие;                         // ключ → сколько раз уже есть в приёмнике
Для Каждого Строка Из Приёмник Цикл
	Было.Вставить(Ключ(Строка), ?(Было[Ключ(Строка)] = Неопределено, 0, Было[Ключ(Строка)]) + 1);
КонецЦикла;
Для Каждого Строка Из Источник Цикл
	Если Было[Ключ(Строка)] <> Неопределено И Было[Ключ(Строка)] > 0 Тогда
		Было.Вставить(Ключ(Строка), Было[Ключ(Строка)] - 1);   // эта строка уже была — пропустить
		Продолжить;
	КонецЕсли;
	ЗаполнитьЗначенияСвойств(Приёмник.Добавить(), Строка);
КонецЦикла;
```

**Ключ — то, что различает строки источника.** Реквизит в шапке и в табличной части — разные строки; если в
приёмнике нет поля, которое их различает (табличная часть), его нужно добавить — иначе и пользователь их не
различит.

**Проверять на данных с повторами.** Перед тестом «все строки» — посчитать в источнике строки и разные ключи
(`СГРУППИРОВАТЬ ПО … ИМЕЮЩИЕ КОЛИЧЕСТВО(*) > 1`); если повторов нет — найти объект, где они есть. Ожидаемое число в
тесте — строки источника, а не разные ключи.

**Подбор по такому источнику** — значение один раз, места — в представлении («Реквизит (шапка, ТЧ1, ТЧ2)»):
`СписокЗначений` + `Соответствие` значение → массив мест, представление собрать после обхода.
