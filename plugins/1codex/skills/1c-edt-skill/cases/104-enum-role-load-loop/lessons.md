# Симптом → причина → правило

LoadConfigFromFiles не завершается, журнал пуст, процесс постоянно использует CPU.
Воспроизведено с записью Enum в роли: сначала Read+View, затем только View.
Удаление записи при сохранении нового перечисления и его включения в подсистему устраняет зависание.
Внутренняя причина зацикливания платформы не установлена; на другие версии результат не обобщать.

Не создавать перечислениям права по образцу справочника. Доступ к использующим перечисление реквизитам
задавать через права их объекта. Поддерживаемые права сверять с рабочей выгрузкой.

Диагностические загрузки выполнять на копии базы с ограничением времени. Не печатать TimeoutExpired целиком:
его текст включает командную строку с параметрами авторизации. Выводить только имя операции и срок ожидания.
