# Присваивание локальной структуры попало в контекст формы

Проект: UP, ФМ01.7, 30.10.2026. Платформа 8.5.1.1529, совместимость 8.5.1.
Собственная конфигурация, XML Конфигуратора, управляемое приложение без БСП.
Confidence: HIGH для воспроизведённого имени и сценария на этой платформе.

В обработчике StartChoice поля версии структуры требовалось открыть форму выбора
с отбором по объекту текущей строки. CheckModules прошёл, но настоящий вызов
из формы выдал: «Ошибка при установке значения атрибута контекста
(ПараметрыВыбора): Несоответствие типов».

Полный стек указал на присваивание структуры, стоящее перед ОткрытьФорму.
Переименование в НастройкиФормыВыбораВерсии устранило ошибку без изменения
сигнатуры ОткрытьФорму. В проекте исправление подтверждено повторным UI-вызовом.
При оформлении этого кейса платформа повторно не запускалась.
