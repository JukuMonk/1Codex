# T10 — форма выбора с отбором из другой формы

По `examples/bsl/open-form-with-callback.bsl`:

```bsl
&НаКлиенте
Процедура ОбъектНачалоВыбора(Элемент, СтандартнаяОбработка)
	СтандартнаяОбработка = Ложь;
	ПараметрыОткрытия = Новый Структура;
	ПараметрыОткрытия.Вставить("Отбор", Новый Структура("Активен", Истина));
	ПараметрыОткрытия.Вставить("ТекущаяСтрока", Объект.Объект);
	ОткрытьФорму("Справочник.ПримерСправочник.ФормаВыбора", ПараметрыОткрытия, Элемент,,,,
		Новый ОписаниеОповещения("ОбъектВыборЗавершение", ЭтотОбъект));
КонецПроцедуры

&НаКлиенте
Процедура ОбъектВыборЗавершение(Результат, ДополнительныеПараметры) Экспорт
	Если Результат <> Неопределено Тогда
		Объект.Объект = Результат;
		Модифицированность = Истина;
	КонецЕсли;
КонецПроцедуры
```

В Form.form у поля `Объект` — `<handlers><event>StartChoice</event><name>ОбъектНачалоВыбора</name></handlers>`
сразу после `</dataPath>` (case 027).

Отчёт обязан объяснить: `ПараметрыВыбора` элемента типовой/стандартный
обработчик начала выбора не передаёт в форму, которую открывает сам
(case 036), поэтому форму открываем явно; имя `Параметры` занято формой
(case 010); продолжение — экспортная клиентская процедура.
