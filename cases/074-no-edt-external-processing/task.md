# Доработка без EDT: внешняя обработка над данными расширения

**Объекты.** Внешняя обработка «АЗОТ Анализ потерь материальных потоков» над справочниками и регистрами расширения (ХТП, МТР, нормы, пороги, влияния, распределение).

**Проект: КАО АЗОТ (1С:ТОИР КОРП 3.0.8.1 + расширение ФРЕГАТ `дс_ОбменДаннымиСПромежуточнойБД`, платформа 8.3.27, режим совместимости 8.3.21, без EDT).**

**Задача.** Реализовать ТЗ методолога в базе, развёрнутой из `.dt`, без проекта EDT: только пакетный Конфигуратор, COM и тонкий клиент.

**Что пошло не так по дороге (каждое — минуты разбора).**
1. Частичная загрузка расширения из его же нетронутой выгрузки: «Исключение XDTO … Catalogs/рсм_Функции/Forms/ФормаСписка/Ext/Form.xml» (заимствованная форма).
2. Сборка `.epf` с типом `cfg:CatalogRef.<объект расширения>`: «Неизвестное имя типа».
3. `ObjectModule.bsl` в `<корень>/Ext` вместо `<корень>/<Имя>/Ext`: сборка код 0, методов у объекта нет.
4. Переменная `И` в модуле: «Неопознанный оператор» (это логическое «и»).
5. Переменная `Окно` в модуле формы: «Поле объекта недоступно для записи (Окно)».
6. `Возврат Новый Файл(Путь).Существует();` — «Неопознанный оператор».
7. Через COM `o.Реквизит = None` не очищает `ЛюбаяСсылка` — потеря на стадии осталась, тест «пропал».
8. UI-тест: у `ТестируемаяФорма` нет `Закрыть`; диалог БСП «база перемещена» перехватывает фокус в копии базы.

**Результат.** Обработка собрана из XML (`tools/designer_lib.py`), ядро сверено с независимой реализацией на Python (499 норм, расхождений 0), 50 шагов настоящих нажатий в тонком клиенте прошли. Конфигурация и расширение не изменены.

**Confidence:** HIGH (всё проверено прогоном на 8.3.27).
