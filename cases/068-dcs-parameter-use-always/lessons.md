# Уроки

**Симптом.** Отчёт падает «Не задано значение параметра Сценарий», если в настройках варианта параметр выключен (галочка использования снята).

**Почему.** Параметр без `{…}` в тексте запроса нужен всегда; выключенный в настройках — не передаётся. `use=Always` заставляет СКД передавать его независимо от флага использования.

**Что изменилось.** `dcs_schema_ex` пишет `<use>Always</use>` всем параметрам; значение по умолчанию для ссылочного параметра — пустая ссылка (DesignTimeValue), а не условие ССЫЛКА в запросе.

**Правило.** Параметр, стоящий в запросе без фигурных скобок, — use=Always и осмысленное значение по умолчанию.
