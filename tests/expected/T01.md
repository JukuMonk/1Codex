# T01 — новый справочник

Ожидаемый ход (любой из двух):

**А. scaffold + правка спецификации.**
```bash
python tools/scaffold.py tests/sandbox catalog ПримерСправочник ТестКонтрагенты --synonym "Контрагенты (тест)"
```
Затем в `.mdo` заменить реквизиты на нужные (`edt_lib.attribute`), в
формах — пути данных. Проще — вариант Б.

**Б. библиотекой.** Скрипт по образцу `tools/make_examples.py`:
```python
L.catalog_mdo('ТестКонтрагенты', 'Контрагенты (тест)',
    attributes=[('ИНН', 'ИНН', 'Строка(12)'), ('Активен', 'Активен', 'Булево'),
                ('Тип', 'Тип', 'Перечисление.ПримерПеречисление', 'обязательный')],
    tabular_sections=[{'name': 'Контакты', 'synonym': 'Контакты',
        'attributes': [('Имя', 'Имя', 'Строка(100)'), ('Телефон', 'Телефон', 'Строка(20)')]}],
    forms=[('ФормаЭлемента', 'Форма элемента'), ('ФормаСписка', 'Форма списка')],
    default_forms=[('defaultObjectForm', 'ФормаЭлемента'), ('defaultListForm', 'ФормаСписка')])
```
+ формы через `field`/`object_tabular_table`/`dynamic_list_table` +
`register_in_configuration(config, 'Catalog', 'ТестКонтрагенты')`.

Признаки верного результата:

- `Catalogs/ТестКонтрагенты/ТестКонтрагенты.mdo`, `Forms/ФормаЭлемента/Form.form`
  (+ `Module.bsl`, если объявлен обработчик), `Forms/ФормаСписка/Form.form`;
- реквизит `Тип`: `<fillChecking>ShowError</fillChecking>` между `maxValue` и
  `fillValue`; у реквизитов ТЧ нет `fillValue`; `producedTypes` полный набор
  (objectType, refType, selectionType, listType, managerType);
- `Configuration.mdo`: строка в `<catalogs>` последней; подсистема
  `ПримерГруппа`: `<content>Catalog.ТестКонтрагенты</content>` и
  `Catalog.ТестКонтрагенты.Command.Открыть`(нет — для справочника команда
  формы списка: `Catalog.ТестКонтрагенты`) в `.cmi`; роль: `Read`, `View`;
- uuid — `uuid5` (повторная генерация даёт те же);
- `python tools/check_project.py tests/sandbox` → 0 ошибок;
- отчёт: структурная проверка пройдена; в базе не проверялось; новый
  объект требует полного обновления (case 020).

Типичные ошибки: колонка ТЧ пронумерована с 1 (case 003); нет
`saveWindowSettings` (case 002); реквизит ТЧ с `fillValue` (case 025);
объект не добавлен в подсистему («до него не добраться»).
