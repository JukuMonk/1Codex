# T13 — мобильный экран

Основа — `examples/mobile/mobile-form` (`mobile()` в `tools/make_examples.py`)
или `python tools/scaffold.py tests/sandbox mobile ПримерМобильная ТестМобильная`
с последующим упрощением до двух страниц.

Признаки:

- `.mdo`: `<forms>` с двумя `<usePurposes>` (MobileDevice, PersonalComputer),
  `<defaultForm>`; у корня `Configuration.mdo` — `MobileDevice` (в песочнице
  есть; отчёт называет это условием — case 005);
- `Form.form`: `Pages` → `PagesGroupExtInfo` с `pagesRepresentation
  TabsOnTop` (Swipe — только у страниц, по строкам его нет — case 030);
  страница «Сейчас»: `LabelDecoration` жирным, два `InputField` `readOnly`,
  `Button` `UsualButton` с `horizontalStretch true`, `defaultButton` у
  главной, цвета `backColor/textColor/borderColor` (`page_button(...,
  'главная')`, `'осторожно'`); страница «Список»: `Table` с
  `commandBarLocation None`, `searchStringLocation/viewStatusLocation/
  searchControlLocation None`, спутники на месте (case 004), три
  `InputField` колонки только чтения, без `CheckBoxField` (case 041);
- реквизиты: объект `ТекущийОбъект`/`Объект` (главный —
  `DataProcessorObject.ТестМобильная`), таблица с колонками в общем
  пространстве номеров, числовые — с `numberQualifiers` (case 001);
- команды `Выполнено`, `НеПолучается` → `&НаКлиенте` процедуры, зовущие сервер;
- `check_project` 0 ошибок; отчёт: в мобильном клиенте не проверялось.
