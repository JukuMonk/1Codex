# Форма записи регистра сведений — ФормаЗаписи

**Что демонстрирует.** `InformationRegisterManagerFormExtInfo`; реквизит
`Запись : InformationRegisterRecordManager.ПримерНедоступность` (`main`,
`savedData`); пути данных `Запись.Объект`, `Запись.НедоступенС`…; группа
`AlwaysHorizontal` с двумя датами шириной 16 + `autoMaxWidth` (строка «с …
по …» не расползается по колонкам — cases 007, 008); вертикальные группы
`WeakSeparation`. HIGH — та же сборка, что боевая форма записи
недоступности техники.

**Обязательные файлы.** `ПримерНедоступность/Forms/ФормаЗаписи/Form.form`;
в .mdo регистра — `<forms>` + `defaultRecordForm` (ставится ДО
`dataLockControlMode` — case 039).

**Что можно менять.** Поля по измерениям/ресурсам/реквизитам регистра;
группы. Для периодического регистра добавить поле `Запись.Период`.

**Что согласовано.** Имена в путях данных ↔ `.mdo` регистра
(`examples/metadata/information-register`); модуля нет — умолчания записи
при необходимости ставить в `ПриСозданииНаСервере` (`Запись.НедоступенС = ТекущаяДата()`).

**Похожее.** `forms/simple-item-form` (форма объекта), `knowledge/managed-forms.md` §5;
`reference/InformationRegisters/мвмНедоступностьТехники/Forms/ФормаЗаписи`.
