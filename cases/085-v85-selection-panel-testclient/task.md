# 8.5: команды формы на панели множественного выделения таблицы; тест-клиент 8.5.1 — кнопка выбора, запись, долгие сценарии

**Проект и платформа.** «ФРЕГАТ: управление проектами» (`C:\gold\UP`), своя конфигурация без БСП, платформа
8.5.1.1529, совместимость 8.5.1, интерфейс «Такси» 8.5, без EDT (XML Конфигуратора, пакетный Конфигуратор, COM,
TestClient); ДиЗ-03 и ДиЗ-04 к ТЗ-01 «АРМ Методолог», 17.10.2026.

**Задача.** В таблице «Реквизиты» формы версии структуры — групповое заполнение и очистка колонок («Обязательность»,
«Тип», «Символов») в выделенных строках; подборы «флажками» (реквизиты версии, шаги другого сценария, сценарии
другого ТЗ). Проверка — настоящими нажатиями (уровень 9) со снимками по пунктам для отчёта заказчику.

**Что пошло не так.**
1. Кнопки «Заполнить выделенные…» / «Очистить выделенные…» добавлены в командную панель таблицы, у команд
   `SelectedRowsUse=Use` (`before/команда_без_таблицы.xml`). Пока выделена одна строка — кнопки видны; как только
   выделено несколько (флажки 8.5 слева или Ctrl+A), 8.5 заменяет панель таблицы тёмной **панелью множественного
   выделения** («47 ×», вверх, вниз, удалить) — своих кнопок на ней нет, то есть пользоваться групповой правкой нельзя.
2. В подборах сделана своя колонка-флажок «Пометка» — в 8.5 у таблицы уже есть родные флажки выделения: на снимке два
   переключателя в строке.
3. Тест-клиент: `ТестируемоеПолеФормы.НажатьКнопкуВыбора()` — «Метод объекта не обнаружен»; `Выбрать()` у строковой
   колонки с кнопкой выбора (`TextEdit=false`, своя форма по `StartChoice`) — «Неподходящий тип элемента управления»,
   после чего следующий шаг висит до таймаута; нажатие стандартной `ФормаЗаписать` формы объекта висит до таймаута.
4. Сценарий на 50 шагов по формам с реальными данными (~20 с на шаг) не укладывается в 900 с ожидания журнала —
   «журнала нет» выглядит как зависание.
5. Документация 8.5.1 на ИТС без входа не читается (web_fetch отдаёт оглавление) — ответ на п.1 искали «по памяти».
