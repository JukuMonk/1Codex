# Установка 1Codex для коллег

1Codex — плагин разработки 1С без EDT. Нужны актуальное настольное приложение
ChatGPT/Codex с поддержкой плагинов, вход в свой аккаунт и доступ к GitHub.
Для сборки и запуска конфигураций нужна установленная платформа 1С.

## Windows: один раз установить

1. Откройте https://github.com/JukuMonk/1Codex/tree/plugin .
2. Через **Code → Download ZIP** скачайте ветку `plugin` и распакуйте архив.
3. В распакованной папке откройте PowerShell и выполните:

   ```powershell
   .\Install-1Codex.ps1
   ```

4. Перезапустите настольное приложение. В **Plugins → Installed** должен появиться
   **1Codex**. Начните новый чат и напишите: «Используй 1Codex. Настрой разработку
   1С без EDT. Версия платформы …, папка проекта …».

Установщик подключает публичный GitHub-каталог, устанавливает плагин и создаёт
задачу **1Codex-Update** для вашего пользователя: проверка ежедневно в 12:00
и при входе в Windows. Администраторские права и пароль не нужны. Если компьютер
выключен или сеть недоступна, обновление будет получено при следующей проверке.
Новая версия используется в новом чате; при необходимости перезапустите приложение.

Если Windows блокирует запуск скрипта, можно разблокировать два скачанных файла
через **Свойства → Разблокировать**, если это допускается правилами вашей организации.
Скрипты не меняют ExecutionPolicy. Если запрещены PowerShell-скрипты или задачи,
используйте ручные команды ниже или обратитесь к администратору.

## Установка командами (Windows/macOS/Linux)

Нужны доступные команды `codex` и `git`. В Windows установщик умеет находить
CLI, поставляемый настольным Codex. Для других установок сначала добавьте
актуальный Codex CLI в PATH.

```text
codex plugin marketplace add https://github.com/JukuMonk/1Codex.git --ref plugin
codex plugin add 1codex@1codex
```

Затем перезапустите приложение и начните новый чат. Для Windows без фоновой
задачи можно запустить `Install-1Codex.ps1 -NoSchedule`.

## Получить обновление сейчас

В Windows запустите в PowerShell:

```powershell
& "$env:USERPROFILE\.codex\1codex-updater\Update-1Codex.ps1"
```

Или вручную в терминале с доступным `codex`:

```text
codex plugin marketplace upgrade 1codex
codex plugin add 1codex@1codex
```

На macOS/Linux эти команды обновляют плагин вручную; Windows-установщик на этих
системах не применяется. Архив повторно скачивать не нужно. В Windows журнал:
`%USERPROFILE%\.codex\1codex-updater\update.log`.

## Если не появился или нужно удалить

- Проверьте версию приложения и `codex plugin marketplace list`.
- Проверьте `codex plugin list --marketplace 1codex --json`.
- Если прежний `1c-edt-skill` установлен отдельно, отключите старую копию,
  чтобы не использовать два одинаковых навыка.
- Отключить автообновление: Планировщик заданий → **1Codex-Update** → Отключить.
- Удалить: сначала отключите задачу, затем выполните
  `codex plugin remove 1codex@1codex` и `codex plugin marketplace remove 1codex`.

Плагин не устанавливает платформу 1С и не получает доступ к базам автоматически.
Для настройки конкретного проекта используйте отдельную тестовую базу.
