# 1Codex — разработка 1С в Codex без EDT

Набор знаний, 109 кейсов и инструменты разработки 1С. Историческое имя сохранено;
основной режим — иерархическая XML-выгрузка Конфигуратора и BSL.
Точка входа — `SKILL.md`, правила Codex — `knowledge/codex.md`.

[Инженерный атлас — открыть красивую страницу в браузере](https://JukuMonk.github.io/1Codex/)

## Плагин для коллег и обновления

[Простая инструкция установки](docs/INSTALL.md) ·
[Как владельцу публиковать обновления](docs/UPDATES.md).

Меняйте исходный навык в `main` и отправляйте изменения в GitHub. GitHub Actions
проверяет пакет и обновляет готовый плагин в ветке `plugin`. Коллеги один раз
устанавливают его из этой ветки; Windows-установщик включает ежедневное обновление.
Источник материалов один, готовый пакет вручную редактировать не нужно.

## Установка на другие компьютеры

Для передачи в формате плагина ChatGPT/Codex см. [упаковку плагина](packaging/README.md).
Сборка: `python packaging/build_plugin.py --output <папка-вне-репозитория>`.
Исходный навык и его способ установки ниже сохраняются.

Репозиторий: https://github.com/JukuMonk/1Codex (публичный).
Для чтения и установки приглашение в GitHub не требуется.
Техническое имя навыка остаётся `1c-edt-skill`, вызов в Codex — `$1c-edt-skill`.

В PowerShell на каждом компьютере:

```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.agents\skills" | Out-Null
git clone https://github.com/JukuMonk/1Codex.git "$env:USERPROFILE\.agents\skills\1c-edt-skill"
```

Если папка уже существует, не перезаписывайте её: используйте существующую
копию или сохраните свои изменения перед заменой. При необходимости перезапустите Codex.

Получить обновления:

```powershell
git -C "$env:USERPROFILE\.agents\skills\1c-edt-skill" pull --ff-only
```

Изменения навыка публикуются обычными коммитами и `git push` с того компьютера,
где они сделаны. Вход в Codex и доступ к GitHub настраиваются отдельно.
Настройки конкретных баз, установленная платформа 1С и зависимости Python
на каждый компьютер переносятся или устанавливаются отдельно.

Основа: [Fregat-vrn/1c-edt-skill](https://github.com/Fregat-vrn/1c-edt-skill).
Исходная история и авторство сохранены. Эта редакция адаптирована для Codex без EDT.

## Начало работы

Для готовой выгрузки:

```powershell
python tools/new_project.py <выгрузка> <папка-инструментов> --prefix <префикс> --name "Название"
```

По умолчанию — Codex и Конфигуратор. Команда строит карту, создаёт `AGENTS.md`,
`.gitignore` и образец настроек. Существующие инструкции и настройки не
перезаписываются. База, COM-регистрация и GitHub автоматически не изменяются.
Для пустой конфигурации сначала получить выгрузку пустой базы выбранной версии:
`knowledge/new-project.md`.

## Инструменты

| Файл | Назначение |
|---|---|
| `tools/designer_lib.py` | Метаданные, формы, внешние обработки, пакетный Конфигуратор |
| `tools/config_map.py` | Карта объектов, реквизитов, форм и модулей |
| `tools/lint_dump.py` | Проверки BSL и запросов до загрузки |
| `tools/ui_test.py` | Реальные действия через TestManager/TestClient |
| `tools/ui_capture.py` | Снимки видимых окон тестового клиента |
| `tools/vanessa.py` | Постоянные сценарии Vanessa |
| `tools/run_timed.py` | Время команды и код возврата без транскриптов Claude |
| `tools/check_links.py` | Ссылки набора; принят файл пользователя с рабочего стола |
| `tools/cases_sync.py` | Проверка кейсов и указателя |

`platform.py load/quick/screens/forms` — исторический конвейер EDT, здесь
не используется. Общие BSL-проверки и построитель СКД из `edt_lib` пригодны
без EDT. Старые инструменты Claude не используются в Codex.

`knowledge/`, `cases/`, `reference/` сохраняют накопленные знания.
`examples/` и `tests/sandbox/` — исторические примеры EDT, не готовая конфигурация
Конфигуратора. Их самопроверка не заменяет проверку будущей конфигурации в 1С.

```powershell
python tools/check_links.py
python tools/cases_sync.py проверить
python tools/check_project.py tests/sandbox
```

Набор используется из одной локальной папки; проектная ссылка
`.agents/skills/1c-edt-skill` ведёт на неё. Инструкции проекта — в `AGENTS.md`.
Совместимость со старыми проектами сохранена явным режимом
`new_project.py --format edt --agent claude`.
