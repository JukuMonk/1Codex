# Перенос данных при переходе «доработанная конфигурация → поставка + расширение»

**Проект и платформа.** НПЦАП (`C:\gold\NPCAP`), 1С:ТОИР КОРП 3.0.8.1 → та же поставка (и 3.0.25.3) + расширение
`НПЦАП_Доработки` (кейс 081), платформа 8.3.27.2342, файловая демобаза (~2 300 проведённых документов). Октябрь 2026.

**Задача.** Рабочую базу с доработками в конфигурации перевести на чистую поставку с расширением так, чтобы данные
доработок (реквизиты типовых объектов, объекты `дс_*`, поля типовых регистров) сохранились. Доказать это сверкой.

**Что пошло не так.**
1. Без переноса реструктуризация удаляет колонки новых реквизитов и таблицы своих объектов; объекты расширения с
   теми же именами — ДРУГИЕ объекты метаданных (новые пустые таблицы). Данные доработок теряются молча.
2. `/UpdateDBCfg` после загрузки поставки: «Записи регистра сведений стали неуникальными: ЦеныНоменклатуры» — ушло
   измерение `дс_Серия`, строки одного товара с разными сериями совпали по ключу.
3. После загрузки предопределённых элементов своего справочника — удвоение (9 → 18): расширение уже создало свои
   предопределённые с другими ссылками.
4. Сверка «до/после» показала различия в 4 объектах при совпадающем числе — порядок выборки без `УПОРЯДОЧИТЬ`
   после реструктуризации другой.
5. Отчёты через COM: «Connect.ТипЗнч» (глобального `ТипЗнч` нет); `Метаданные.РегистрыСведений[имя]` — «This object
   does not support enumeration»; `cn.XDTOСериализатор` — AttributeError; КТГ отличался в последнем месяце — отчёт
   обрезает период текущим моментом, прогоны разнесены во времени.
