# Отчёт с параметрами периода и группировкой — ПримерОтчетПоПериоду

**Что демонстрирует.** Схема с параметрами `НачалоПериода`/`КонецПериода`
(`xs:dateTime`, `StandardBeginningDate` с вариантами `BeginningOfThisDay` /
`BeginningOfNextDay`, `use Always`), запросом с `МЕЖДУ &НачалоПериода И
&КонецПериода`, отбором по ссылке, итогом и двухуровневой группировкой
`День → Объект` с детальными записями внизу (case 035). HIGH — сборка
боевого «Журнала рейсов» (`reference/Reports/мвмЖурналРейсов`).

**Обязательные файлы.**

```
ПримерОтчетПоПериоду/ПримерОтчетПоПериоду.mdo
ПримерОтчетПоПериоду/Templates/ОсновнаяСхемаКомпоновкиДанных/Template.dcs
```

Регистрация — как у `metadata/report`.

**Что можно менять.** Запрос, поля, параметры (`edt_lib.dcs_schema(parameters=…)`
— только даты; другие типы параметров брать с типового отчёта), группировки.

**Что согласовано.** `Документ.ПримерДокумент` в запросе ↔
`metadata/document`; `Справочник.ПримерСправочник.ПустаяСсылка` в отборе.

**Похожее.** `knowledge/skd.md` §2–3; `examples/skd/README.md`; `metadata/report`.
