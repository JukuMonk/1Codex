# 076 — НачатьПомещениеФайлов с диалогом: «Несоответствие типов (параметр номер '4')»

**Симптом.** Кнопка загрузки файлов в тонком клиенте падает сразу, до открытия диалога:
«Ошибка при вызове метода контекста (НачатьПомещениеФайлов) … Несоответствие типов (параметр номер '4')».
Компилятор EDT и проверка модуля молчат; Vanessa, которая форму только открывает, ошибку не видит.

**Причина.** Вариант с диалогом выбора: `НачатьПомещениеФайлов(Оповещение, ПомещаемыеФайлы, ДиалогВыбораФайла,
Интерактивно, ИдентификаторФормы)` — после диалога идёт булево «Интерактивно», идентификатор формы — пятым.
Написано было по памяти `(Оповещение, , Диалог, УникальныйИдентификатор)` — УИД попал в «Интерактивно».

**Исправление.** `НачатьПомещениеФайлов(Оповещение, , Диалог, Истина, УникальныйИдентификатор);` — так в
типовых (Конфигурация UP, КонсольЗапросов). Или асинхронно: `Ждать ПоместитьФайлыНаСерверАсинх(, , Диалог,
УникальныйИдентификатор)`.

**Ловит.** `check_bsl` (правило 8 в `edt_lib.check_bsl`).

**Урок.** Сигнатуры методов платформы с несколькими вариантами — брать из живого кода типовой (`grep` по
`src/`), а не по памяти; кнопки, открывающие файловый диалог, сценарий Vanessa не проверяет — нажать вручную.
