# Симптом → причина → правило

Проверка модулей не гарантирует, что присваивание в модуле формы создаёт локальную
переменную: имя может разрешиться как изменяемое свойство контекста формы.
В воспроизведённом сценарии `ПараметрыВыбора = Новый Структура(...)` дало
ошибку установки атрибута контекста из-за несовместимого типа.

Не занимать имя `ПараметрыВыбора` для структуры открытия формы. Использовать
имя по назначению, например `НастройкиФормыВыбораВерсии`. Правило дополняет
кейс [010](../010-form-module-reserved-names/lessons.md); это не полный перечень
зарезервированных имён для всех версий платформы.

При ошибке выбора сначала получить полный текст и стек и найти точную строку.
Не менять параметры `ОткрытьФорму` по короткому сообщению «Несоответствие типов»:
исключение может возникнуть раньше, при подготовке аргументов.

Проверка исправления: CheckModules, затем настоящий вызов выбора в форме,
проверка отбора, выбор значения и возврат в исходную строку. COM-запись ссылки
не выполняет обработчик StartChoice и не заменяет этот UI-сценарий.
