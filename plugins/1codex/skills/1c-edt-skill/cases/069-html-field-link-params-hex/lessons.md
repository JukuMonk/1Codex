# Уроки

**Симптом.** Щелчок по сектору/строке графика: «Переменная не определена (СпособКодированияСтроки)» в модуле формы на клиенте.

**Почему.** Системное перечисление `СпособКодированияСтроки` в этом контексте клиента недоступно (режим совместимости / тонкий клиент), а браузерное кодирование ещё и зависит от движка поля HTML.

**Что изменилось.** Страница кодирует параметр hex (4 цифры на символ, любые буквы и пробелы), модуль формы раскодирует своей функцией — без платформенных декодеров.

**Правило.** Параметры из страницы в 1С — в собственной тривиальной кодировке (hex), проверенной на клиенте; ссылки вида `#префикс-действие-параметр`.
