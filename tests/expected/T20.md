# T20 — запись из пакета с пропусками

```bsl
	Записанные = Новый Массив;
	Для Каждого Описание Из Пакет Цикл
		Если НЕ ЗначениеЗаполнено(Описание.Имя) Тогда
			ОставитьПропущенный(Записанные, Описание, "пустое имя");   // case 044
			Продолжить;
		КонецЕсли;
		Записанные.Добавить(ЗаписатьОбъект(Описание));
	КонецЦикла;
	ПометитьЛишнее(Записанные);          // лишнее = чего нет в ПАКЕТЕ, а не что не записалось

	// украшение — не роняет данные (case 043)
	Попытка
		ПересчитатьСводку();
	Исключение
		СообщитьПользователю("Сводка не пересчитана: " + ОписаниеОшибки());
	КонецПопытки;
```

`ОставитьПропущенный` добавляет в `Записанные` ссылку существующего объекта
(если он уже есть в базе) и пишет причину в сообщения — иначе объект,
которого нет в списке записанных, будет помечен как лишний и исчезнет молча
(транзакция фиксируется). Отчёт называет оба кейса и то, что «молча» —
худший вид ошибки.
