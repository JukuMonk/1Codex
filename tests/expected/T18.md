# T18 — агрегат по строке неограниченной длины

`МАКСИМУМ(ВЫРАЗИТЬ(Элементы.Комментарий КАК СТРОКА(150))) КАК Комментарий`.

Объяснение: `Комментарий` — Строка(0) (неограниченная); в агрегатах,
группировках, сравнениях и `РАЗЛИЧНЫЕ` такие поля запрещены —
«Неверные параметры МАКСИМУМ» при выполнении, компилятор молчит (case 031).
Длина в `ВЫРАЗИТЬ` — по смыслу (усечение). То же для `СГРУППИРОВАТЬ ПО`
такому полю. `check_bsl.py` предупреждает о `МАКСИМУМ(поле)` без `ВЫРАЗИТЬ`,
но длин полей не знает — смотреть тип в .mdo.
