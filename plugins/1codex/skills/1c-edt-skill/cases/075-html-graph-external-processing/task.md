# Граф потоков в поле HTML внешней обработки: свой движок в JS, сверка с 1С, мост и фантом тестового клиента

**Объекты.** Форма «Граф потоков» внешней обработки «АЗОТ Анализ потерь материальных потоков»: поле HTML, страница из текстового макета, интерактивная регулировка порогов и коэффициентов с пересчётом каскада в странице, «Применить в модель» → буфер основной формы.

**Проект: КАО АЗОТ (1С:ТОИР КОРП 3.0.8.1, платформа 8.3.27, тонкий клиент, без EDT).**

**Что пошло не так.**
1. Страница в Edge застряла на «Загрузка…», а `js_errors` пуст: синтаксическая/ранняя ошибка основного скрипта гасит и его же `window.onerror`; `--dump-dom` вдобавок не показывает значение `textarea`, выставленное из JS.
2. После «Применить в модель» заголовок «Изменения (1)», а таблица изменений (и журнал) в тестовом клиенте пустые. Три «исправления» (вызов в контексте своей формы, заполнение строк вместо подмены коллекции, перенос в табличную часть объекта) не помогли — данных хватало, не было отрисовки: вкладки, ни разу не показанные, активированные шагом `ТестируемаяГруппаФормы.Активизировать()` после возврата из окна графа, остаются пустыми. Программное `Элементы.Страницы.ТекущаяСтраница = …` показывает строки.

**Результат.** Движок страницы сверен с модулем объекта на 7 сценариях × 499 норм (0 расхождений, режим `#selftest` в headless Edge против COM); мост страница → 1С (очередь `bridge_out`, подтверждение `out_ack`) проверен настоящим прогоном в тонком клиенте с автотестом страницы.

**Confidence:** HIGH (8.3.27, тонкий клиент; Edge 2026 headless).
