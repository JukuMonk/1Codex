# Уроки

**Симптом.** «Процедура или функция с указанным именем уже определена (Состояние)» при старте ТОЛСТОГО клиента с файловой базой. В тонком клиенте и на сервере всё работало месяц.

**Почему.** У толстого клиента есть глобальный метод `Состояние()`, и серверные общие модули там компилируются в процессе клиента: `Функция Состояние(…) Экспорт` конфликтует с ним. Вылезло только при профилировании — профилировщик EDT запускает толстый клиент.

**Что изменилось.** Функция переименована в `СостояниеРейса`; имена функций сверяются со списком глобальных методов (`Сообщить`, `Состояние`, `Формат`, `Мин`, `Макс`, `Строка`, `Число`, `Найти`…) — `tools/check_bsl.py`.

**Коммиты.** MVM 2b73215.
