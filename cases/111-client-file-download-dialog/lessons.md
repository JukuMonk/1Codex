# Выбор каталога и получение результата
Относительное имя не задаёт папку назначения клиента. Не путать число аргументов
старого callback-метода и асинхронного метода с параметрами диалога.
В Асинх/Ждать-варианте передать ПараметрыДиалогаПолученияФайлов; результат —
одно описание файла либо Неопределено при отмене. Флажок «сохранено» ставить
после завершения передачи, не после формирования JSON на сервере.

Перед проверкой удалён старый тестовый файл; новый JSON получен на клиенте,
все 2039 строк совпали с серверным журналом. Тестовая сборка подставляет
полный путь вместо диалога; производственная сборка открывает окно получения
файла, что отдельно подтверждено TestClient и снимком. Полный проход системного
выбора папки автоматикой не проверялся. Методы записи кодов этим исправлением
не менялись. Не объявлять экспорт проверенным по одному открытию формы.
