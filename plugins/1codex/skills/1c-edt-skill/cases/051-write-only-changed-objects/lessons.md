# Уроки

**Симптом.** Запись карты 13,5 с при правке одного узла. Профиль: `ПолучитьОбъект()` и `Записать()` на каждый из 924 узлов и 957 проездов; половина времени — типовые проверки при записи (даты запрета, обмен); `Строка(Ссылка)` в имени ходила за представлением на каждый.

**Почему.** Пакет от карты всегда полный, и сервер писал всё подряд, не сравнивая с тем, что лежит в базе.

**Что изменилось.** Текущие значения читаются одним запросом на весь пакет (`УзлыДляСравнения`), объект открывается на запись только когда отличается хоть одно поле; числа сравниваются с точностью реквизита (`ЧислаРавны(А, Б, Знаков)` — карта шлёт длинный хвост, база хранит три знака). 13,5 с → 1,1 с.

**Коммиты.** MVM 63407ce.

**Ссылки.** `knowledge/bsl.md` §5, §9; cases 052, 053.
