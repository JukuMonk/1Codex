# Уроки

**Правило раскладки.** Поле без ширины (наименование, тексты, ссылки «на всю строку») — `stretch=True`;
поле с шириной (коды, номера, перечисления, ссылки фиксированной ширины) — `width=N, stretch=False`;
табличная часть на всю форму — `max_width=False`. Важные колонки — слева: окно может оказаться уже
таблицы.

**Ширина окна-диалога** — по самой широкой строке полей; чтобы форма с большой таблицей открывалась
шире, расширять строку полей над таблицей (тег ширины формы не проверен — LOW).

**Как проверять.** Глазами в тонком клиенте: Vanessa `--video` по формам (`vanessa.py`), кадр через
2–3 с после открытия каждой формы.

**Ссылки.** case 008 (узкие поля: width + autoMaxWidth), case 007 (свойства групп), case 074.
