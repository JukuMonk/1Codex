# reference — боевые образцы: «если нужно создать X — смотри …»

Файлы скопированы из проекта-источника (1C:EDT, конфигурация на базе
1С:ТЛЭиУА КОРП 1.1.36.1, платформа 8.3.24) как есть: реальные имена с
префиксом `мвм`, реальные uuid. Они РАБОТАЮТ в базе — это и есть их
ценность: сомневаешься в теге, порядке, свойстве — открой файл здесь, а не
вспоминай. Двоичные макеты (Template.bin), картинки подложек и большие
HTML-макеты не скопированы. Учётных данных, адресов и персональных данных в
файлах нет (проверено скриптом `tools/check_links.py --sensitive`).

## Генераторы (`generators/`)

Показывают технику: идемпотентные правки XML и модулей по якорям-содержимому.
Пути проекта-источника внутри — как были; для своего проекта переписать
(`knowledge/generators.md`).

| Скрипт | Техника |
|---|---|
| `формы_edt.py` | вывод реквизита/ТЧ на существующую форму: поле в группу, колонка в таблицу, вкладка с таблицей; точки вставки по содержимому; `Ид` для номеров |
| `метаданные_edt.py` | спецификация объектов наверху → .mdo справочников/перечислений/регистров + регистрация; uuid из файла или uuid5 |
| `подсистема_логистики.py` | раздел с группами: состав (`ВЕРХНИЙ`, `ГРУППЫ`), `parentSubsystem`, cmi, картинка; ПАДАЕТ, если объект проекта не внесён в состав |
| `упростить_форму_заказа.py` | правка ТИПОВОЙ формы: вставки в модуль (`insert_into_procedure`), своя область, константа (case 037), `--проба` |
| `время_заказа_на_форме.py` | группы с четырьмя свойствами (case 007), поля `width`+`autoMaxWidth` (case 008), `образец.поле` в порядке EDT (case 027) |
| `поиск_пунктов_на_форме.py` | панель поиска над списком (`verticalStretch` — case 009), клиентская+серверная процедуры (case 033) |
| `проба_мобильной_формы.py` | лесенка проб `--убрать`: с какого элемента форма перестаёт рисоваться (case 006) |
| `выделить_правки.py` | HEAD → генераторы → diff с файлом пользователя (case 027) |
| `проверить_экспорт_edt.py` | `1cedtcli export` в чистое рабочее пространство — проверка файлов без EDT (case 028) |

Общая библиотека для всего этого в pack'е — `tools/edt_lib.py` (переписана
на нейтральные имена и латинские идентификаторы).
