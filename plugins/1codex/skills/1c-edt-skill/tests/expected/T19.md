# T19 — чужой помощник

Верно: `ЧислоИлиНоль` объявляется в самом общем модуле (в области
`СлужебныеПроцедурыИФункции`, без `Экспорт`) — как в
`examples/metadata/common-module/ПримерОбщийМодуль/Module.bsl`.

Почему компилятор молчит: общий модуль компилируется (проверяется) при
первом обращении в сеансе, а не при обновлении конфигурации; имя из модуля
ФОРМЫ общему модулю не видно — в бою «{ОбщийМодуль.X.Модуль(N,M)}:
Процедура или функция с указанным именем не определена (ЧислоИлиНоль)»
(case 013).

Неверно: сделать функцию формы экспортной (у модуля формы экспорт не даёт
доступа из общего модуля); вынести в третий модуль ради трёх строк
(допустимо, но правило pack'а — мелкие помощники свои в каждом модуле).
`check_bsl.py` на общем модуле (`--common`) сообщит о вызове без префикса,
если имя объявлено в другом проверяемом файле; `check_project` сверяет все
`мвм*`-модули проекта вместе.
