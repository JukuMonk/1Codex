# examples — рабочие образцы

Правило pack'а: **WORKING EXAMPLE > ABSTRACT KNOWLEDGE > MODEL MEMORY**.
Новый объект начинается с копии примера того же вида (`tools/scaffold.py`),
а не с чистого листа.

Все примеры собраны `python tools/make_examples.py` библиотекой
`tools/edt_lib.py`, скелеты элементов которой сняты с форм и объектов,
работающих в бою (`reference/`). Каждая форма при сборке проходит
`check_form` (номера, спутники таблиц, пути данных, обработчики в модуле),
каждый .mdo — `check_mdo`; все примеры вместе образуют песочницу
`tests/sandbox/` (`python tools/make_sandbox.py` → `tools/check_project.py`
без ошибок). Предметные имена заменены нейтральными (`Пример…`).

| Папка | Пример | Что демонстрирует |
|---|---|---|
| `metadata/enum/` | ПримерПеречисление | перечисление с тремя значениями |
| `metadata/catalog/` | ПримерСправочник | справочник: реквизиты четырёх типов, ТЧ, формы элемента и списка |
| `metadata/constant/` | ПримерУпрощённыйРежим | булева константа-переключатель |
| `metadata/information-register/` | ПримерНедоступность | независимый регистр сведений с формами записи и списка |
| `metadata/accumulation-register/` | ПримерОстатки | регистр остатков (MEDIUM) |
| `metadata/document/` | ПримерДокумент | документ с ТЧ, движениями и формой (MEDIUM) |
| `metadata/common-module/` | ПримерОбщийМодуль | серверный общий модуль с вызовом сервера и запросами |
| `metadata/data-processor/` | ПримерОбработка | обработка: таблица значений, командная панель, три команды |
| `metadata/report/` | ПримерОтчет | отчёт на СКД: отбор по ссылке и строке, группировка, детальные записи |
| `metadata/role/` | ПримерРоль | роль: права запуска и права на объекты |
| `metadata/subsystem/` | ПримерРаздел + ПримерГруппа | раздел с дочерней подсистемой, командным интерфейсом и картинкой |
| `metadata/configuration-registration/` | Configuration.mdo | регистрация объектов и назначения использования |
| `forms/simple-item-form/` | ФормаЭлемента | форма элемента: группы, поля, ТЧ-таблица объекта |
| `forms/list-form/` | ФормаСписка | динамический список с группой настроек |
| `forms/record-form/` | ФормаЗаписи | форма записи регистра, строка «с… по…» |
| `forms/html-field-form/` | ПримерКарта | поле HTML, макет страницы, мост через DOM-поля |
| `mobile/mobile-form/` | ПримерМобильная | мобильная форма: страницы, таблицы, кнопки на странице |
| `reports/report-with-parameters-and-grouping/` | ПримерОтчетПоПериоду | отчёт с параметрами периода и двухуровневой группировкой |
| `bsl/` | фрагменты | модуль формы, открытие формы с оповещением, отбор списка, запросы, регистры, таймер |
| `skd/` | — | указатель на схемы компоновки и их правила |

Как пользоваться:

1. Найти нужный вид в таблице, прочитать README примера (что можно менять).
2. `python tools/scaffold.py <корень EDT> <вид> <ИмяВПримере> <НовоеИмя>` —
   копия с переименованием, свежими uuid5 и регистрацией в Configuration.mdo.
3. Менять только то, что README называет изменяемым; структуру (порядок
   тегов, спутники, свойства групп) не трогать.
4. `python tools/check_project.py <корень EDT>` → EDT → база → платформа
   (`knowledge/validation.md`).

Пересобрать примеры после правки библиотеки: `python tools/make_examples.py`,
затем `python tools/make_sandbox.py` и `python tools/check_project.py tests/sandbox`.
