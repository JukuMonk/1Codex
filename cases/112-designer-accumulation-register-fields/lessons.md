# Ресурсы и измерения регистра накопления — свой состав свойств

`md_field` по умолчанию добавляет FillFromFillingValue/FillValue. Эти свойства
не входят в Resource и Dimension регистра накопления. Использовать `fill=False`.
Построитель `tools/designer_lib.py` (`accumulation_register_xml`) использует
порядок из XML-образца и новые устойчивые идентификаторы, не чужие UUID.

Загрузка может вернуть код 0 и перечислить неверные свойства в журнале.
Поэтому проверять журнал вместе с кодом возврата, а затем обратную выгрузку.
В исправленном варианте загрузка без замечаний, UpdateDBCfg и CheckModules
успешны; приход, расход и отчёт проверены через COM на отдельной копии базы.
Обратная выгрузка регистра совпала с генератором.

Структурный образец: [MyMoney, исходник автора](https://github.com/fokusov/MyMoney/blob/master/AccumulationRegisters/ДвижениеДенегПоСчетам.xml).
Сверка на 8.3.27 выполнена в проекте «Учебный склад»; образец старой версии
сам по себе такую совместимость не доказывает.
