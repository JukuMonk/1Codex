# Внешняя компонента Native API без Visual Studio (zig), опрос станков FANUC FOCAS прямо из 1С

**Проект и платформа.** ФРЕГАТ ПУЛЬС (`C:\gold\ZHDRM`), своя конфигурация без EDT и БСП, 8.3.27.2342, совместимость
8.3.21, файловые базы; итерация 15 (17–18.10.2026). Машина — Windows Server, пользователь без прав администратора,
Visual Studio нет.

**Задача.** Заказчик (машиностроение) хочет, чтобы 1С сама опрашивала станки с ЧПУ раз в ~5 с, без промежуточных
узлов (шлюзов, ПК у станков). FANUC читается только через FOCAS — библиотеку FANUC (`Fwlib64.dll`), из встроенного
языка недоступную. Нужно: внешняя компонента Native API (C++), подставная библиотека FOCAS для разработки без станка,
подключение в конфигурацию (узел `focas://IP:8193`, каналы, состояния, регламентное задание), тесты через COM.

**Что пошло не так.**
1. Компилятора нет, ставить VS нельзя (нет прав). Взяли zig (`pip install --user ziglang`, clang внутри) — он
   собирает под Windows в режиме MinGW (`x86_64-windows-gnu`, Itanium C++ ABI), а платформа собрана MSVC. В MSVC
   виртуальный деструктор занимает в vtable одну ячейку, в Itanium — две: все методы интерфейсов Native API
   (`IInitDoneBase`, `ILanguageExtenderBase`, `IMemoryManager`, `IAddInDefBase`) сдвинулись бы на ячейку.
2. libc++ не собирает `std::basic_string<uint16_t>` (под Linux `WCHAR_T` = `uint16_t`) — сборка Linux упала.
3. `ПодключитьВнешнююКомпоненту("<путь>\Компонента.zip", …, Native)` → Ложь, затем «Тип не определен (AddIn.…)»;
   та же DLL по пути — подключается. Манифест был ни при чём.
4. Проверка подставной DLL из Python (ctypes): `cnc_statinfo(...) == -8` ложно — ctypes по умолчанию читает возврат
   как `int`, а FOCAS возвращает `short`.
5. Bash: файл с кириллическим именем, созданный heredoc'ом, Python не открыл (имя потерялось); скрипты правки с
   кавычками в heredoc срывали разбор; Python под Windows не понимает пути `/c/...`.
6. Показание пишется «на сейчас», а даты 1С — до секунды: расчёт состояния «до сейчас» ничего не строил; двоичный
   сигнал (1/2) с порогами вход = выход отвергнут классификатором (нужен гистерезис) — состояние UNKNOWN.

**Результат.** Компонента (Windows x64 + Linux x64 в одном zip) загружается в 1С из общего макета (тип `AddIn`),
методы вызываются правильно; опрос параллельный (станок без связи ждёт свой таймаут 1 с — весь цикл 1,01 с);
`тест_чпу.py` 25/25 на подставной FOCAS; загрузка, `/CheckModules`, сверка 0 из 310. Реальный станок FANUC не проверялся
(нет доступа); Linux-сборка собрана, но не запускалась.

**Confidence:** HIGH — ABI-поправка и подключение из макета/временного хранилища (проверено в 1С 8.3.27 через COM);
MEDIUM — раскладка структур FOCAS (по открытому описанию; подставная библиотека собрана по тому же заголовку и
расхождения не покажет); LOW — Linux-сборка (не запускалась).
