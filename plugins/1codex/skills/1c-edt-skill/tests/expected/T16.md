# T16 — выбросить запрос из пакета

Из `fixtures/packet.bsl` удаляется второй запрос ВМЕСТЕ с одним
разделителем — тем, что стоит после него (или перед ним), но не обоими и
не ни одним:

```
		|	НЕ Элементы.ПометкаУдаления
		|;
		|
		|////////////////////////////////////////////////////////////////////////////////
		|ВЫБРАТЬ
		|	Записи.Объект КАК Объект,
```

Два `|;` подряд = пустой запрос → «Ожидается выражение "ВЫБРАТЬ"», весь
пакет не выполняется (case 046).

Чтение результатов — поимённо и с пересчётом (case 042):

```bsl
	ЭлементыЗапрос = 0;
	НедоступныеЗапрос = 1;              // был 2
	Результаты = Запрос.ВыполнитьПакет();
	Сводка.Вставить("Элементы", Результаты[ЭлементыЗапрос].Выгрузить());
	Сводка.Вставить("Недоступные", Результаты[НедоступныеЗапрос].Выгрузить());
```

Строки про `Активных` удалены. `check_bsl.py` молчит; в отчёте — что
позиция — единственная связь запроса с результатом, и сдвиг молчит до
первого обращения к полю, которого в «чужом» результате нет («Поле объекта
не обнаружено»).
