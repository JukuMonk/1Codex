# Регистр сведений — ПримерНедоступность

**Что демонстрирует.** Независимый непериодический регистр: измерение
`Объект` (ссылка на справочник, `master`), ресурсы `НедоступенС`,
`НедоступенПо` (ДатаВремя), `Причина` (Строка(100)); формы записи и списка,
ссылки на них ДО `dataLockControlMode` (case 039). Имена ресурсов —
нарочно не `С`/`По`: ключевые слова запросов запрещены как имена (case 016).
HIGH.

**Обязательные файлы.**

```
ПримерНедоступность/ПримерНедоступность.mdo
ПримерНедоступность/Forms/ФормаЗаписи/Form.form    ← копия examples/forms/record-form
ПримерНедоступность/Forms/ФормаСписка/Form.form
```

Регистрация: `<informationRegisters>InformationRegister.ПримерНедоступность</informationRegisters>`.

**Что можно менять.** Измерения/ресурсы/реквизиты (`edt_lib.information_register_mdo`
падает на ключевых словах); `informationRegisterPeriodicity` (Nonperiodical /
Day / …) и `writeMode` — образца периодического регистра здесь нет (LOW),
брать с типового. Формы — по образцу `forms/record-form`.

**Чтение и запись.** `examples/bsl/register-read-by-query.bsl`:
`Получить` возвращает структуру всегда — наличие записи проверять запросом
(case 018); одна актуальная запись на объект — набор с отбором по измерению.

**Что согласовано.** uuid `stable_uid('InformationRegister/…')`; пути
данных формы записи `Запись.Объект`, `Запись.НедоступенС`… ↔ имена в .mdo;
общий модуль `ПримерОбщийМодуль` пишет и читает этот регистр.

**Похожее.** `knowledge/metadata.md` §5; `reference/InformationRegisters/
мвмНедоступностьТехники` (боевой, с формами), `мвмКэшМаршрутов` (кэш,
case 018), `мвмНастройкиКарты` (ключ → значение, где `Получить` уместен).
