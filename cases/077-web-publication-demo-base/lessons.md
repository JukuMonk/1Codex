# Уроки

**Веб-модуль — той же версии, что платформа базы.**
- Модуль 8.5.1 на базе ТОИР 3.0 (8.3.27) уронил httpd в компоненте лицензирования СЛК, с 8.3.27 всё работает.
- Один Apache загружает только один `_1cws_module`. Если соседние публикации на другой версии, нужен ОТДЕЛЬНЫЙ экземпляр:
  - свой конфигурационный файл и `Listen`;
  - свои `PidFile` и журналы;
  - `httpd -k install -n <служба> -f <conf>`.
- Ставит его администратор; рабочий Apache не перезапускается, сеансы его пользователей не рвутся.
- Как найти причину: «Сеанс отсутствует или удален» сразу после входа → журнал приложений Windows, «Application Error», сбойный модуль. В журнале Apache: `child process exited with status 3221225477`.

**Проверка публикации без прав администратора.** Тот же конфигурационный файл запустить в консоли: `httpd -f <копия.conf>`.
- `PidFile`, `ErrorLog` и `CustomLog` перенести в доступный каталог; порт — свободный.
- Браузер на `http://127.0.0.1:<порт>/<имя>/ru_RU/`.
- Для теста — копия базы, если неясно, не изменит ли другая версия платформы её формат.

**Внешняя обработка — в «Дополнительные обработки» через COM.**
- Вызов: `ДополнительныеОтчетыИОбработки.ЗарегистрироватьОбработку(Объект, Параметры)`. В параметрах:
  - `АдресДанныхОбработки` — `ПоместитьВоВременноеХранилище(ДвоичныеДанные)`;
  - `ЭтоОтчет`, `ОтключатьКонфликтующие`, `ИмяФайла`, `ОтключатьПубликацию`.
- Дальше вручную: `Публикация = Используется`, `ХранилищеОбработки = ХранилищеЗначения(дд)`.
- Разделы: начальная страница — ПУСТАЯ ссылка `ИдентификаторыОбъектовМетаданных`, раздел — `ИдентификаторОбъектаМетаданных(Метаданные.Подсистемы.X)`. Список допустимых разделов — в `ДополнительныеОтчетыИОбработкиПереопределяемый`.
- Быстрый доступ — `ДополнительныеСвойства.БыстрыйДоступ`: таблица с колонками `ИдентификаторКоманды`, `Пользователь`.
- В копиях баз проверить константу `ИспользоватьДополнительныеОтчетыИОбработки`: без неё команды нет нигде.
- В ТОИР команда видна в разделе («Оборудование и нормативы → Дополнительные обработки»), на начальной странице её не было.

**Снимки тестового клиента — фильтр по своему порту** (`TPort 48123`), а не по `TESTCLIENT`: на общем сервере может параллельно идти UI-прогон другого проекта, и в инструкцию попадёт чужое окно.

**Apache 2.2 под Windows:** в `Allow from` нет `::1`, только IPv4. Файлы публикации — с CRLF. Батник с кириллицей: `chcp 65001` второй строкой, файл UTF-8 без BOM.

**Безопасность.**
- Сервер виден из интернета: в журнале доступа — сканеры с внешних адресов. Копия рабочей базы с «Администратором» без пароля — не открывать всем, пока пароль не задан.
- Задавать пароль и решать, открывать ли публикацию, — пользователю. Скрипт спрашивает и по умолчанию открывает только локально.
