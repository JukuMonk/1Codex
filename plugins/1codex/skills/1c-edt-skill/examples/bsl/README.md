# examples/bsl — фрагменты модулей

Каждый файл — самостоятельный фрагмент модуля формы (или общего модуля),
который можно вставить в свой модуль целиком или по процедурам. Имена
объектов — из `examples/metadata` (ПримерСправочник, ПримерНедоступность,
ПримерОбщийМодуль…); замените на свои.

| Файл | Что показывает | Правила / кейсы |
|---|---|---|
| `form-module-skeleton.bsl` | Каркас модуля формы: области, директивы у каждой процедуры, клиент → «…НаСервере», открытие формы без занятого имени `Параметры` | cases 010, 011, 012; `knowledge/bsl.md` §1–2 |
| `open-form-with-callback.bsl` | Открыть форму выбора с `Отбор`/`ТекущаяСтрока`, продолжение экспортной процедурой; вопрос пользователю через оповещение | case 036; `knowledge/managed-forms.md` §8 |
| `dynamic-list-filter.bsl` | Отбор динамического списка из `Параметры.Отбор` и полей поиска через `ОтборыСписковКлиентСервер`; плоский вид при отборе; клиентская и серверная версии одного тела | cases 033, 036; `knowledge/managed-forms.md` §8 |
| `conditional-appearance.bsl` | Условное оформление таблицы из модуля вместо XML; прямой цвет надписи для мобильной формы | `knowledge/managed-forms.md` §4, case 041 |
| `query-patterns.bsl` | Формат запросов как в типовой; пакет с именованными индексами; иерархический справочник без групп; ТЧ через запрос; пустые строки в коде | cases 015, 016, 017, 031, 042, 046; `knowledge/bsl.md` §4 |
| `register-read-by-query.bsl` | Независимый регистр: запись набором, чтение запросом, где уместен `Получить`; `ОбменДанными.Загрузка` при записи чужого объекта | cases 014, 018; `knowledge/bsl.md` §5 |
| `hide-by-constant.bsl` | Упрощённый вид типовой формы под константой: перенос групп и скрытие в модуле, умолчания после типовых | cases 026, 037 |
| `timer-refresh.bsl` | Обработчик ожидания: подключение в `ПриОткрытии`, отключение на время записи, дешёвый ключ «что изменилось» | `knowledge/html-field-and-templates.md` §4 |

Все фрагменты проходят `python tools/check_bsl.py <файл>` (для
`register-read-by-query.bsl` и `query-patterns.bsl` — ключ `--hier
ПримерИерархическийСправочник`, потому что запрос к нему отсекает группы).
Проверка структурная: она не заменяет прогон в базе (`knowledge/validation.md`).
