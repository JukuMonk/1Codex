Почему двух остатков недостаточно

Учебная иллюстрация, не результат запуска 1С

Операция должна быть отклонена: минимум внутри периода −1.

Серая линия показывает исходную историю, пунктир показывает результат выбранного изменения. Через COM проверяются остатки по событиям. UI-сценарий проверяет отказ и сообщение пользователю. После отказа прежние движения должны сохраниться.
