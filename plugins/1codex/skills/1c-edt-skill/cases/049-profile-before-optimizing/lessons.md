# Уроки

**Симптом.** Автораздача 120 заявок — 104 с. «На сотнях узлов перебор — доли секунды» оказалось неправдой при сотне маршрутов.

**Почему.** Профиль (цель «Сервер»): 13 млн итераций перебора минимума по всем узлам и 78 загрузок графа из справочников — граф читался заново на КАЖДЫЙ маршрут. Клиентский профиль (0,2 с) про серверную работу ничего не говорил.

**Что изменилось.** Ближайший узел берёт двоичная куча (`КучаДобавить`/`КучаВзять`, ленивое удаление); граф читает модуль с повторным использованием на время сеанса, поэтому функция БЕЗ параметров и без учёта машины, а проходимость решается при обходе (`ПроездДоступен`). Итог 104 с → 8 с. Профилировать серверный код с целью «Сервер»; профилировщик запускает толстый клиент (case 047).

**Коммиты.** MVM 98230b3, ebe2fa1.
