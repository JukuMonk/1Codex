# Своя конфигурация 1С с нуля без EDT: построители объектов, полная загрузка, сверка обратной выгрузкой

**Проект и платформа.** ЖДРМ ПУЛЬС (ФРЕГАТ, `C:\gold\ZHDRM`), самостоятельная конфигурация (без БСП и типовой),
платформа 8.3.27.2342, совместимость 8.3.21, файловая база, октябрь 2026.

**Задача.** Развернуть подход «без EDT» (АЗОТ, кейс 074) для НОВОЙ конфигурации: метаданные — генератором
(спецификация на Python → XML Конфигуратора), модули — руками, загрузка пакетным Конфигуратором, проверка
через COM и TestManager. В `designer_lib` до этого были только обработки и формы.

**Что пошло не так.**
1. Построителей справочника, перечисления, регистра, документа, общего модуля, подсистемы, роли,
   регламентного задания, константы, команды в `designer_lib` не было.
2. Посев через COM: канал не прошёл `ПроверитьЗаполнение()` — «Поле "Наименование" не заполнено»:
   наименование составляет `ПередЗаписью`, а проверка идёт до записи (та же ошибка ждала пользователя в форме).
3. Посев через COM: `datetime(2026,10,9,0,0)` записался в 1С как `08.10.2026 21:00` (машина в MSK).
   `cn.Тип('Дата')`/`cn.Type('Date')` — AttributeError: глобального `Тип` через COM нет.
4. UI-тест: менеджер (`/TESTMANAGER /Execute ТестUIМенеджер.epf`) молча стоял — окно «Предупреждение
   безопасности» при открытии внешней обработки; в базе без пользователей защиту не снять.
5. Edit не находил фрагмент модуля после генератора: тот привёл .bsl к BOM+CRLF, а Write сохранил
   «пустые» строки без табуляции.

**Результат.** Итерация 1 (5 справочников, 3 перечисления, 3 подсистемы, роль) загружена ПОЛНОЙ загрузкой,
`/CheckModules` чисто, обратная выгрузка совпала с исходником по содержанию (0 расхождений из 21 файла),
посев идемпотентен, UI-сценарий 11 шагов ОК.

**Confidence:** HIGH для справочника, перечисления, подсистемы, роли, общего модуля, регистра сведений (и периодического), команды,
формы обработки, константы, регламентного задания (загружено и сверено); MEDIUM для документа (собраны по выгрузке
ТОИР КОРП, загрузкой ещё не проверены).
