# T17 — чтение регистра

Эталон — `examples/bsl/register-read-by-query.bsl`, функция `Недоступность`:
`ВЫБРАТЬ ПЕРВЫЕ 1 … ГДЕ Записи.Объект = &Объект И Записи.НедоступенПо > &Сейчас`,
`Если НЕ Выборка.Следующий() Тогда Возврат Неопределено`.

Отчёт: `РегистрыСведений.X.Получить(Отбор)` возвращает структуру с
ПУСТЫМИ ресурсами, если записи нет, и никогда — `Неопределено`; проверка
`= Неопределено` не срабатывает, а пустой ресурс читается как ответ
(case 018: кэш «находил» отрицательный ответ до первого расчёта). `Получить`
уместен только там, где пустое значение и отсутствие записи означают одно и
то же (настройки).

Неверно: `Получить` + `Если Запись = Неопределено`; `Получить` + проверка
`ЗначениеЗаполнено(Запись.НедоступенПо)` — формально работает для этого
регистра, но правило pack'а — запрос (сказать, если выбран этот путь).
