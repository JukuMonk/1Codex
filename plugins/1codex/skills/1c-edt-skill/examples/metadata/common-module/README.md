# Общий модуль — ПримерОбщийМодуль

**Что демонстрирует.** Серверный общий модуль с вызовом сервера
(`server`, `serverCall`, без `global`): экспортные функции зовутся из
клиентского кода форм. Модуль: запрос к справочнику, запись независимого
регистра набором, чтение регистра ЗАПРОСОМ (case 018), собственный помощник
`ЧислоИлиНоль` (не тянуть из чужого модуля — case 013). HIGH.

**Обязательные файлы.**

```
ПримерОбщийМодуль/ПримерОбщийМодуль.mdo
ПримерОбщийМодуль/Module.bsl        ← UTF-8 без BOM, CRLF, табуляция
```

Регистрация: `<commonModules>CommonModule.ПримерОбщийМодуль</commonModules>`.

**Что можно менять.** Флаги контекста (`edt_lib.common_module_mdo`:
`server`, `server_call`, `client_managed`, `global_`, `privileged`) — клиентский
модуль (`client_managed=True, server=False`) содержит только клиентский код.
Имя модуля — с префиксом проекта; вызов из форм — `Имя.Функция()`.

**Что согласовано.** uuid `stable_uid('CommonModule/…')`; имена справочника и
регистра в запросах ↔ `metadata/catalog`, `metadata/information-register`.
`check_bsl.py --common` проверяет модуль без правил модуля формы.

`reference/CommonModules/мвмМаршрутизация/мвмМаршрутизация.mdo`, `мвмЧатВодителей` (+ голова
модуля), `мвмРейсыВодителя` — боевые модули с описанием назначения.
