# Уроки

**Симптом.** Начальная страница (форма дашборда в рабочей области) открывается секунды: сервер при создании формы выполняет все запросы панели и подставляет JSON в HTML.

**Почему.** `ПриСозданииНаСервере` блокирует показ формы. Фоновое задание не может вызвать функции модуля формы — расчёт должен жить в серверном общем модуле (или модуле менеджера), экспортная функция возвращает текст JSON.

**Что изменилось.** Расчёт вынесен в общий модуль; форма строит страницу без данных (заставка); после открытия — `ДлительныеОперации.ВыполнитьФункцию` (ОжидатьЗавершение = 0, без окна ожидания); результат уходит в страницу тем же каналом, что кнопка «Обновить» (скрытое поле + подпись, страница опрашивает таймером). Три ловушки: (1) пакет может прийти раньше `ДокументСформирован` — хранить «ожидающий пакет»; (2) смена периода во время расчёта — номер загрузки, устаревший результат отбрасывать; (3) ошибка задания — показать на странице, не всплывающим окном.

**Правило.** Всё тяжёлое на формах начальной страницы — фоном после открытия. Страница поля HTML — «оболочка + пакеты», данные не вшивать в HTML.
