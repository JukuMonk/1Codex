# Начальная страница «Мой спринт»: SVG-картинкой без поля HTML, запись в данные, которые приходят обменом

**Проект и платформа.** «ФРЕГАТ: управление проектами» (UP), своя конфигурация без EDT, 8.5.1.1529, файловая база;
18.10.2026.

**Задача.** Исполнителю на начальной странице — свой спринт (недельный, `Справочник.Спринт.ПланЗадач`): задачи тремя
колонками (не начаты / в работе / завершены), часы по дням, прогресс к плану, работа вне плана; «Записать часы» и
«Завершить» прямо со страницы. Задачи и трудозатраты приходят из Битрикс24 регламентным обменом — сначала проверить,
как запись со страницы с ним сочетается.

**Что сделано.** Обработка `МойСпринт` (`after/мой_спринт.py` — генератор XML, модули — `after/*.bsl`), начальная
страница `OneColumn`; прогресс и дни — одна SVG-картинка в поле картинки; запись — элемент «Учета времени» как ручной
ввод; «Завершить» — флажок «Завершено» записи по задаче и стадии плана. Нажатия (24 шага, 23 с) + COM-проверка записей.
