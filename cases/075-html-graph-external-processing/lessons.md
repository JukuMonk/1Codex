# Уроки

**Страница во внешней обработке.** Макет «Текстовый документ» (`<Имя>/Templates/<Макет>/Ext/Template.txt`, UTF-8 с BOM, CRLF), исходник страницы — отдельный `.html` в проекте, генератор копирует его в макет. Данные — подстановкой JSON вместо заглушки (`var МОДЕЛЬ = /*МОДЕЛЬ*/null;`) на сервере при создании формы (`ПолучитьМакет(...).ПолучитьТекст()` + `СтрЗаменить`); модель передаётся параметром формы строкой JSON (`ЗаписатьJSON` на сервере).

**Свой движок в JS — только со сверкой.** Если страница пересчитывает то же, что модуль 1С (для мгновенной реакции на ползунки), держать индексы общими (узел/МТР — номера из 1С) и сверять: страница в режиме `#selftest` считает сценарии из модели и пишет итог в `<pre>`, Python получает его через `msedge --headless --dump-dom` и сравнивает с результатом COM. Без этого «совпадает» — допущение.

**Диагностика страницы без 1С.** Перехват ошибок — отдельным РАННИМ `<script>` (иначе синтаксическая ошибка основного скрипта гасит и его `onerror`). `--dump-dom` не сериализует `value` полей ввода, выставленное из JS: состояние/ошибки дублировать в `textContent` обычного элемента.

**Мост на 8.3.27 (тонкий клиент).** Страница → 1С: очередь строк «номер\tкоманда\tаргумент» в `textarea#bridge_out`, данные — в отдельном поле, 1С опрашивает раз в секунду (`ПодключитьОбработчикОжидания`), подтверждает номером в `out_ack`; 1С → страница: `value` скрытого поля, страница опрашивает своим таймером. Функции страницы из 1С не вызываются (как в АРМ МВМ, `html-field-and-templates.md` §3). Вызов из формы графа в форму-владелец — экспортной клиентской функцией, а саму работу владелец делает в своём обработчике ожидания.

**Фантом тестового клиента.** Таблица пустая при правильном счётчике («Изменения (1)») — сначала проверить, не артефакт ли отрисовки: вкладка, впервые показанная шагом `Активизировать()` после возврата из другого окна, в тестовом клиенте может остаться пустой. Проверка — переключить вкладку из кода формы (`Элементы.Страницы.ТекущаяСтраница`) или снять кадр после действия, которое форма делает сама; не переписывать работающий код по фантому (здесь ушло три итерации).
