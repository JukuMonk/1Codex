# Уроки

**Симптом.** F7 в Конфигураторе: «В процессе обновления информационной базы
произошла критическая ошибка. Ошибка SDBL: Слишком большое значение
описателя длины». Загрузка файла отклонения не вызывала: XML корректен,
ошибка вылезла на перестроении структуры — «правильный файл, невозможная
структура».

**Почему.** Во всей типовой (30 тыс. файлов) максимум 1024; длинный текст
хранят неограниченной длиной (0) — 1876 случаев.

**Правило.** Строка ≤ 1024 или `Строка(0)`; проверка отвергает больше
(`edt_lib.type_xml`, `check_mdo`).

**Коммиты.** MVM 4d41f68.
