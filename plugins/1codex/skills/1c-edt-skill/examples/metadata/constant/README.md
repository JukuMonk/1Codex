# Константа — ПримерУпрощённыйРежим

**Что демонстрирует.** Булева константа-переключатель поведения с
`explanation` (подсказка в форме констант). Читается
`Константы.X.Получить()` в модуле (`examples/bsl/hide-by-constant.bsl`). HIGH.

**Обязательные файлы.** `ПримерУпрощённыйРежим/ПримерУпрощённыйРежим.mdo`;
регистрация `<constants>Constant.ПримерУпрощённыйРежим</constants>`.

**Что можно менять.** Тип (`type_xml`: Булево, Число, Строка ≤ 1024, ссылка),
синоним, `explanation`. Форму константы не заводим — она нужна редко;
включать константу удобнее через «Все функции» или свою форму настроек.

**Что согласовано.** uuid `stable_uid('Constant/…')`; в подсистеме
`ПримерГруппа` константа стоит в `content` и как команда в `CommandInterface.cmi`.

**Похожее.** `knowledge/metadata.md` §7; case 037 (упрощение типовой формы
под константой); `reference/Constants/мвмУпрощённаяФормаЗаявки` (боевая).
Предупреждение из проекта-источника: константы из XML формата Конфигуратора
грузились с ошибками — в EDT такой проблемы нет, файл ниже загружается.
