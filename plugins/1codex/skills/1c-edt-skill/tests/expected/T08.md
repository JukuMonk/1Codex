# T08 — форма записи регистра

Образец — `examples/forms/record-form` (функция `record_form` в
`tools/make_examples.py`):

```python
items  = L.usual_group(ids, 'Сотрудник', None, L.field(ids, 'Сотрудник', 'Запись.Сотрудник', 4), 2,
                       direction='Vertical', representation='WeakSeparation')
items += L.usual_group(ids, 'Период', None,
             L.field(ids, 'СменаС',  'Запись.СменаС',  4, width=16, max_width=True)
           + L.field(ids, 'СменаПо', 'Запись.СменаПо', 4, width=16, max_width=True), 2,
           direction='AlwaysHorizontal')
items += L.usual_group(ids, 'Примечание', None, L.field(ids, 'Примечание', 'Запись.Примечание', 4, multiline=True), 2,
                       direction='Vertical', representation='WeakSeparation')
attrs  = L.form_attribute(L.Ids(), 'Запись', None, 'InformationRegisterRecordManager.ТестСмены', main=True, saved_data=True)
text   = L.form_file(items, attrs, ext='form:InformationRegisterManagerFormExtInfo', window_mode='LockOwnerWindow')
```

Признаки: у групп `showLeftMargin/united/throughAlign Auto/currentRowUse Auto`
(case 007 — иначе поля разъедутся по колонкам); у дат `width 16` +
`autoMaxWidth true` (case 008); `saveWindowSettings`; ссылка на форму в
.mdo регистра до `dataLockControlMode` (case 039); `check_project` 0.
