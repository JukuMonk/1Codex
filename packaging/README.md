# Пакет плагина 1Codex

Плагин `1codex` содержит основной навык `1c-edt-skill` и вводный навык `setup`.
EDT не используется. В набор входят инструкции, Python-инструменты и 101 кейс.

Установка с обновлениями для коллег:
https://github.com/JukuMonk/1Codex/blob/main/docs/INSTALL.md

Исходный навык поддерживается в `main`; GitHub Actions публикует готовый каталог
плагинов в ветку `plugin`. Для установки используется именно эта ветка.
Windows-установщик создаёт ежедневную задачу обновления для текущего пользователя.
В новых чатах используется полученная версия. Установка не переносит платформу
1С и не предоставляет доступ к локальным базам автоматически.

## Пересборка

`python packaging/build_plugin.py --output <папка-вне-репозитория>` создаёт
переносимый ZIP и комплект локального проекта. Проверяются распаковка, сохранность
ресурсов, Python, указатель кейсов и ссылки. `validation.json` содержит результаты.

`python packaging/publish_plugin.py --output <пустая-папка> --version 1.0.N`
готовит полное дерево ветки `plugin`. Эту команду автоматически вызывает CI.

Проверки архива не заменяют установку в целевом приложении или проверку кода в 1С.
Данный пакет распространяется через GitHub marketplace для настольного приложения.

Основа: https://github.com/Fregat-vrn/1c-edt-skill ; адаптация:

Отдельная лицензия на исходный набор не обнаружена; упаковщик не назначает новую.
